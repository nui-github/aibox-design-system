# v0.51.0 – Steps (nz-steps) ตาม Figma หน้า Steps
วันที่: 2026-11-25

## เพิ่มใหม่
- override ของ `nz-steps` ตาม Figma หน้า Steps (`1504:2619`): ตัวบ่งชี้แนวนอน (`steps-indicator-horizontal` `1504:4345`) = `nzSize="small" nzLabelPlacement="vertical"` ไอคอน 24px เส้น 3px ห่างไอคอนข้างละ 4px หัวข้อ 16/26 และคำอธิบาย 14/24 (กว้างสูงสุด 140px) อยู่กลางใต้ไอคอน
- ตัวบ่งชี้แนวตั้ง (`steps-indicator-vertical` `8528:8912`) = `nzSize="small" nzDirection="vertical"` ไอคอนซ้าย ห่างข้อความ 16px แถวละ 112px เส้น 1px
- ไอคอน: finish = `bg/tertiary` เครื่องหมายถูก `bg/main` 12px, process = `bg/main` ตัวเลขขาว, wait = `bg/disable` ตัวเลข `text/secondary`, error = สีแดง status error กากบาทขาว (หัวข้อและคำอธิบายเป็นสีแดง); ไม่ใส่ `nzSize` = ไอคอน 32px (Basic Default); `nzProgressDot` = จุด 8px (ขั้นปัจจุบัน 10px)
- เส้นเชื่อม: `bg/main` หลังขั้นที่เสร็จแล้ว ที่เหลือ `bg/secondary`
- เว็บเอกสาร: หน้า Steps ใหม่ (แนวนอน, Error, แนวตั้ง, Size / Dot) พร้อมเมนู
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): ตำแหน่งและขนาดไอคอน เส้น หัวข้อ คำอธิบาย และสี ตรงกันทุกเวอร์ชัน (แนวนอน: เส้นเริ่มที่ 4px จากไอคอน หัวข้อห่างไอคอน 8px; แนวตั้ง: แถว 112px เส้นยาว 80px)

## หมายเหตุ
- สีของเส้นอ่านจากตัวแปร Figma (`bg/main`, `bg/secondary`) เพราะรูป SVG ของเส้นเปิดจาก sandbox ไม่ได้: ในตัวอย่าง error ของ Figma เส้นซ้ายของขั้น error ไม่ใช่สีเดียวกับเส้นขวาของขั้นก่อนหน้า (ใช้ component คนละตัว) แต่ override ใช้ "หนึ่งเส้นหนึ่งสี" ตามขั้นที่อยู่ก่อนเส้น ควรให้นักออกแบบยืนยัน
- ยังไม่ครอบคลุม: สถานะ hovered, วงแหวน progress (`nzPercentage`), แบบ navigation และ dark theme
- Figma แสดงตัวบ่งชี้แบบเลขเท่านั้น (ชื่อ "Dot" ใน component คือเลย์เอาต์ ไม่ใช่จุด) ส่วนจุด 8px ของ Progress Icon ใช้กับ `nzProgressDot`
