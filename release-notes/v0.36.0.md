# v0.36.0 – label ห่างจากกล่อง 4px
วันที่: 2026-11-17

## แก้ไข
- label ที่อยู่เหนือช่อง (`nzLayout="vertical"`) ห่างจากกล่อง **4px** ตาม Figma จากเดิม 8px ของ ng-zorro; ข้อความช่วยใต้กล่องห่าง 4px อยู่แล้ว
- label ที่ใส่ `nzRequired` สูงกว่า label ปกติ 2px เพราะ ng-zorro วาดดอกจันสีแดงด้วยฟอนต์ SimSun ขนาด 14px บรรทัดสูง 1 ตอนนี้ดอกจันใช้ฟอนต์และขนาดเดียวกับ label (12/22 หรือ 14/24) ระยะห่างจากกล่องจึงเป็น 4px เท่ากันทั้ง label ปกติและ label ที่จำเป็น
- กล่อง label ใช้ line-height เดียวกับตัว label (เดิม 22px ของ ng-zorro อยู่ในบรรทัด 23px)

## ผลกระทบ
- ทุกฟอร์มแนวตั้ง ระยะ label กับกล่องลดลง 4px (ฟอร์มสั้นลง 4px ต่อช่อง) ฟอร์มแนวนอน (label ข้างช่อง) ไม่เปลี่ยน

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1, 20.4.4 และ 22.1.2 ได้ค่าเท่ากัน: label ถึงกล่อง 4px ทั้ง label ปกติ, label ที่ `nzRequired` และ label ของช่อง large; กล่องถึงข้อความช่วย 4px

## ยังไม่ครอบคลุม
- ฟอร์มแนวนอน (`nzLayout="horizontal"`) และ inline ใช้ระยะของ ng-zorro (Figma ไม่ระบุ)
