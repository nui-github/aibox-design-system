# v0.26.0 – Tree
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ `nz-tree` (รวมรายการต้นไม้ใน `nz-tree-select`) ตาม Figma หน้า Tree Select: tree-selection-list (`9718:69790`) ระดับ 1–5 และ `_base_tree-content-list` (`4267:9343`)
- แถวสูง 42px (padding 8 16 8 8): ลูกศร (กล่อง 20px) ห่าง 8px จาก checkbox ห่าง 8px จากชื่อ 16/26 สี `text/primary`; แต่ละระดับเยื้อง 24px (ระดับแรกเยื้อง 32px เพื่อให้ระดับ 2 เริ่มที่ 40px)
- checkbox ของต้นไม้ (`nzCheckable`) วาดรูปทรงเดียวกับ Checkbox override: กล่อง 17.5px เส้นเทา เลือกแล้วพื้นน้ำเงินเครื่องหมายถูกขาว บางส่วน (indeterminate) สี่เหลี่ยมน้ำเงิน
- hover: พื้นทั้งแถว `bg/tertiary`; node ที่เลือก: ตัวอักษร `color/main` น้ำหนัก medium (สองแบบนี้อ่านจากเฟรม Folder-list)
- หน้า Tree ในเว็บเอกสาร (route `/tree`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| level 1–5 | node ซ้อนกัน (เยื้อง 24px ต่อระดับ) |
| state default / expanded / no sub | ปิด / เปิด (ลูกศรลง) / `isLeaf` (ไม่มีลูกศร) |
| checkbox | `nzCheckable` |
| hovered / selected | hover แถว / node ที่เลือก |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-tree` ทุกตัวเปลี่ยนหน้าตา: แถวสูง 42px มี padding และพื้นขาว ลูกศรสีดำขนาดเล็ก checkbox ถูกวาดใหม่
- ไอคอนลูกศรของ ng-zorro (`caret-down` / `caret-right`) ต้องลงทะเบียนในแอปด้วย
- สี hover / selected เป็นค่าจากรูปแบบ Folder-list (แถวสูง 50px) ที่ผมนำมาใช้กับต้นไม้ checkbox เพราะเฟรม tree-selection-list ไม่แสดงสถานะเหล่านี้ ควรให้ designer ยืนยัน

## ยังไม่ครอบคลุม
- รูปแบบ Folder-list (ลูกศร + ไอคอนโฟลเดอร์ + ชื่อ + chevron ขวา, แถวสูง 50px) เป็นรูปแบบเฉพาะของ product
- สถานะ search (ไฮไลต์คำค้น), ต้นไม้แบบลากวาง / มีเส้น / block node, กล่อง `nz-tree-select` ที่ปิดอยู่ (ใช้สไตล์ช่องของ Select)
- Cascader (เฟรม Cascader Dropdown ที่แถวละไอคอน + ข้อความสองบรรทัด) ยังไม่ได้ทำ
