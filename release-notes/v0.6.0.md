# v0.6.0 – Switch override from Figma

## เพิ่มใหม่
- **Switch override** สำหรับ `nz-switch` ตามดีไซน์ Figma (`switch-text-and-icon` และ `switch`) ใช้ token `--aibox-*` เดิม และเพิ่ม token ใหม่ 2 ตัว (สีเงาของ handle, เงา knob แบบ iOS) จึงมี token รวม 830 ตัว
  - **Desktop** 44×22 (ตรงกับค่าเริ่มต้นของ `nz-switch` พอดี) สถานะ เปิด / ปิด / disabled
  - **Mobile** 50×25 (`class="aibox-switch-mobile"`) และแบบ **iOS** 51×31 (`class="aibox-switch-ios"`)
  - **ไอคอนติ๊ก/✕ ในราง** ใส่ `class="aibox-switch-icons"` (ทำเป็นตัวเลือก)
- README: ตารางจับคู่ Figma → ng-zorro พร้อมตัวอย่างโค้ด และหัวข้อวิธี release

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| switch-text-and-icon, Desktop (44×22) | `<nz-switch>` |
| switch-text-and-icon, Mobile (50×25) | `class="aibox-switch-mobile"` บน `nz-switch` |
| switch (51×31 แบบ iOS) | `class="aibox-switch-ios"` บน `nz-switch` |
| ไอคอนติ๊ก/✕ ในราง | `class="aibox-switch-icons"` บน `nz-switch` |
| Disable = yes | `nzDisabled` |

```html
<nz-switch [(ngModel)]="on"></nz-switch>
<nz-switch class="aibox-switch-icons" [(ngModel)]="on"></nz-switch>
<nz-switch class="aibox-switch-icons aibox-switch-mobile" nzDisabled></nz-switch>
<nz-switch class="aibox-switch-ios" [(ngModel)]="on"></nz-switch>
```

## ที่ต้องรู้ก่อนอัปเกรดจาก 0.5.0
- Switch ทุกตัวบนหน้าจอจะเปลี่ยนสีทันที: เปิด `#1f5df9`, ปิด `#adb0b8`, disabled `#f1f2f3` (ขนาดเริ่มต้น 44×22 ไม่เปลี่ยน) และ **ตอน disabled จะไม่จางด้วย opacity แล้ว** ใช้สีกำหนดตรงตาม Figma
- ไอคอนติ๊ก/✕ จะขึ้นเฉพาะเมื่อใส่ `aibox-switch-icons` **และ**ไม่ได้ใส่ `nzCheckedChildren` / `nzUnCheckedChildren` เอง (กันไอคอนซ้อนกับข้อความที่ใส่เอง) ไอคอนเป็นรูปที่วาดเอง ส่วน Figma ใช้ Font Awesome
- Figma ไม่มี hover/focus ของ switch จึงใช้วงโฟกัสเดียวกับ Input
- `nzSize="small"` (28×16) ไม่มีใน Figma จึงเปลี่ยนแค่สี
- รองรับ `ng-zorro-antd` 18.x

## ยังไม่ครอบคลุม
`nzLoading`, `switch-with-text` (ตัวสลับแบบแบ่งส่วนที่มีข้อความ ไม่ใช่ `nz-switch`; ใกล้เคียง `nz-segmented` มากกว่า), iOS ตอน disabled (Figma ไม่มี ใช้สี disabled ปกติ), dark mode
