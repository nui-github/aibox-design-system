# v0.10.0 – Pagination
วันที่: 2026-11-04

## เพิ่มใหม่
- override ของ `nz-pagination` ตาม Figma (node `3451:10970`): ปุ่มหน้า 32×32 ช่องว่าง 4px มีเงาอ่อน, หน้าปัจจุบันพื้นน้ำเงิน, ปุ่มก่อนหน้า/ถัดไปที่ใช้ไม่ได้เป็นสีเทา, ข้อความรวมด้านซ้าย (`[nzShowTotal]`), ตัวเลือกจำนวนต่อหน้า (`nzShowSizeChanger`) เป็นปุ่มข้อความไม่มีกรอบ ขนาด 12px พร้อมลูกศร 10px
- token ใหม่ `--aibox-pagination-item-shadow` (เงาของปุ่มหน้า ค่าจาก Figma)
- `nzSize="small"` หน้าตาเหมือนขนาดปกติ (Figma มีขนาดเดียว), `nzDisabled` ใช้พื้นและสีตัวอักษร disabled ของปุ่ม

## แก้ไข (Select)
- dropdown ของ `nz-select` กว้างอย่างน้อย 112px: ng-zorro กำหนดความกว้างตาม trigger ซึ่งแคบเกินไปสำหรับ padding และไอคอนติ๊กของ override ทำให้ตัวเลือกถูกตัดคำ (เห็นชัดที่ตัวเลือกจำนวนต่อหน้าของ pagination)

## จับคู่กับ ng-zorro
- ปุ่มหน้าที่ถูกเลือกใช้สี contained standard; ปุ่ม hover ใช้ token ของปุ่ม (Figma ไม่มีสถานะ hover)

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-pagination` ทุกตัวเปลี่ยนหน้าตา: ไม่มีขอบ, ข้อความรวมชิดซ้ายและปุ่มชิดขวา (ใช้ `nzAlign="end"` เมื่อไม่มี `nzShowTotal`)
- dropdown ของ select ทุกตัวกว้างอย่างน้อย 112px (รวมถึง select ที่ trigger แคบกว่านี้)
- ng-zorro ใช้ภาษาจีนเป็นค่าเริ่มต้น ให้ตั้ง locale เอง เช่น `provideNzI18n(th_TH)` และใช้ `items_per_page` ที่สั้น (เช่น "/ หน้า") เพราะ dropdown กว้างตาม trigger

## ยังไม่ครอบคลุม
- dropdown กระโดดไปหน้า (`pagination-dropdown-selection` / `-list` ใน Figma), quick jumper, simple mode, คำนำหน้า "แสดง:" ของ Figma
