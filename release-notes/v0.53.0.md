# v0.53.0 – Progress (nz-progress) ตาม Figma หน้า Progress
วันที่: 2026-11-25

## เพิ่มใหม่
- override ของ `nz-progress` ตาม Figma หน้า Progress (`7630:68366`): Line (แถบสูง 8px มุมกลม ช่องว่างถึงตัวเลข 8px ตัวเลข 14/22; สถานะ success / exception เปลี่ยนตัวเลขเป็นไอคอน 16px; `[nzShowInfo]="false"` = Bare), Line-Mini (`nzSize="small"` แถบ 6px ตัวเลข 12/20), Multiple (`[nzSuccessPercent]` ช่วงสีเขียวทับบนแถบ)
- Circle (`nzType="circle" [nzWidth]="120"` ตัวเลข 24px, Mini `[nzWidth]="80"`) และ Steps (`[nzSteps]` ช่อง 14×8 ห่าง 2px, small 2×6)
- สี: แถบ `--aibox-color-main`, ราง `bg/secondary`, success `bg/status/success-200`, exception `text/status/error-100`, ตัวเลข `text/primary` (Steps ใช้ `text/secondary`) และฟอนต์ Ai-BOX
- เว็บเอกสาร: หน้า Progress ใหม่ (Line, Line mini / Multiple, Circle, Steps) พร้อมเมนู
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): ขนาดแถบ / ราง / ตัวเลข ตำแหน่งตัวเลข สีเต็ม / ราง / success / exception ของ Line, Mini, Multiple, Steps และ Circle เท่ากันทุกเวอร์ชัน (14 รูปแบบเทียบกัน ไม่มีส่วนต่าง)

## หมายเหตุ
- หน้า Progress ใน Figma เป็น Ant Design ดั้งเดิม ไม่ได้ใช้ token ของ aibox (แถบ `#1890ff`, ราง `#f5f5f5`, success `#52c41a`, exception `#f5222d`, ฟอนต์ Roboto) มีเพียง Line-Mini ที่ใช้ `--aibox-color-main` override จึงเก็บ "ขนาดและระยะ" ตาม Figma แต่ใช้สีและฟอนต์ของ Ai-BOX แทน ถ้านักออกแบบต้องการสีของ Ant เดิม ให้แจ้ง (เปลี่ยนที่เดียว) ราง `#f5f5f5` ใช้ `bg/secondary` (`#f1f2f3`) ซึ่งใกล้เคียงที่สุด
- ค่าเริ่มต้นของ circle ใน ng-zorro คือ 132px ต้องส่ง `[nzWidth]="120"` (หรือ 80) ให้ตรง Figma เพราะ ng-zorro ตั้งขนาดเป็น inline style
- ng-zorro ลงสีช่องที่เสร็จของ Steps ผ่าน `nzStrokeColor` เท่านั้น (ไม่มี class ให้จัดสไตล์) ต้องส่ง `nzStrokeColor="var(--aibox-color-main)"`
- ยังไม่ครอบคลุม: แถบไล่สี (`nzStrokeColor` แบบ gradient), แบบ dashboard, dark theme; ไอคอน success / exception ในวงกลมใช้ไอคอนของ ng-zorro ไม่ใช่รูปจาก Figma
