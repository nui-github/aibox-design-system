# v0.8.1 – Button as a link

## แก้ไข
- `<a nz-button>` ข้อความไม่ลอยขึ้นอีก: ng-zorro ตั้ง `a.ant-btn { padding-top: .01px !important }` ทำให้ padding บนหาย override คืนค่า padding-top ตามขนาด (md 8px, lg 12px, sm 8px, xs 4px) ความสูงและตำแหน่งตัวอักษรเท่ากับ `<button nz-button>` ทุก type และทุกขนาด
- ตรวจกับ ng-zorro-antd 18.2.1 และ 22.1.2

## ที่ต้องรู้ก่อนอัปเกรด
- เฉพาะปุ่มที่เป็น `<a nz-button>` จะสูงขึ้นเป็นความสูงตาม Figma (md 40, lg 48, sm 32, xs 24) เดิมเตี้ยกว่าเพราะ padding บนหาย
