# v0.7.0 – Tag / status badge

## เพิ่มใหม่
- override ของ `nz-tag` ตาม badge ใน Figma (Chip & Tag, node `1:10717`): พื้นอ่อน สี/ตัวอักษรตามสถานะ, ขนาด small (สูง 24, ตัวอักษร 14), ทรงแคปซูล, ไม่มีเส้นขอบ
- class เสริม: `aibox-tag-solid` (พื้นเข้ม ตัวอักษรขาว), `aibox-tag-square` (มุม 4px), `aibox-tag-xs` (2xsmall, 12px)

## จับคู่กับ ng-zorro
- ไม่ใส่ `nzColor` = draft; `success` / `processing` / `warning` / `error` = สถานะเดียวกัน; `purple` = rework; `orange` = reject

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-tag` ทุกตัวเปลี่ยนหน้าตา (ไม่มีขอบ, ทรงแคปซูล, margin-right 8px)

## ยังไม่ครอบคลุม
- badge ชนิด signer in progress (pink) และ form, badge disabled, chip (assist/input/filter), checkable tag
