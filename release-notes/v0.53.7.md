# v0.53.7 – ปรับ popup Select / ช่วงวันที่ / ตาราง ตามรายงานเทียบเว็บ (ชุดที่ 2)
วันที่: 2026-11-26

## แก้ไข
- ระยะห่าง popup กับช่องของ Select (รวม Tree select, Cascader ที่ใช้ `.ant-select-dropdown`) เป็น 2px ทั้งเปิดลงและเปิดขึ้น (Figma select-search expanded / Cascader: gap 2) เดิม 18/19 เป็น 4px (margin) และ 22 เป็น 4px (เลื่อน overlay pane)
- popup ของ range picker ไม่มีลูกศรแล้ว (Figma ไม่มี) ระยะห่างจากช่อง 2px (เดิม ~12.7px บน ng-zorro 22 เพราะลูกศร 16px)
- Time picker: มุมโค้งของ popup เป็น 4px (เดิม 6px อ่านผิดจาก Figma node 1613:9329 ซึ่งใช้ `aibox/radius/2`) token `--aibox-timepicker-menu-radius` ชี้ไป `radius.2`
- Table: เส้นแถวใช้ `border/primary` (เดิม `bg/secondary`), hover แถวใช้ `bg/subtlest` #fbfbfd ตาม Figma (เดิม #fafafa ของ ng-zorro), คอลัมน์ checkbox กว้าง 52px, ปุ่มใน action cell ใช้ texted small (32px) ติดกันได้ (แบบ xsmall + `aibox-btn-nopad` ห่าง 20px ยังใช้ได้ แต่ระยะ 20px ใช้กับคู่ `aibox-btn-nopad` เท่านั้น)

## Token ใหม่
- `--aibox-color-bg-subtlest` (= `color.global.gray.80` #fbfbfd) มีใน Figma แต่ขาดใน repo; `--aibox-table-row-hover-bg` ชี้ไปที่ token นี้

- ตรวจ popup gap (Select ลง/ขึ้น, date, range) บน 18.2.1, 19.3.1, 20.4.4, 21.3.3, 22.1.2: ได้ 2px เท่ากันทุกเวอร์ชัน time picker 2px บน 21/22 และ 3px บน 18-20 (ไม่ได้แก้ในรอบนี้)
- ตารางตรวจบน 22.1.2 เท่านั้น: เส้นแถว #f1f2f3 และ hover #fbfbfd วัดแล้ว; คอลัมน์ checkbox 52px ยังไม่ได้วัด (หน้า Table ของเว็บไม่มี demo ที่มี checkbox)
