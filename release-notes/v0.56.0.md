# v0.56.0 – กรอบ Checkbox / Radio ตาม Figma (20 / 24 / 28)
วันที่: 2026-11-27

ตามคำตอบของคุณ: ขยายพื้นที่ให้เท่ากรอบ Figma โดยกล่องที่เห็นไม่เปลี่ยนขนาด

## เปลี่ยน
- Checkbox และ Radio: ทุกตัวมีกรอบ 20 / 24 / 28px (`aibox-sm` / ปกติ / `aibox-lg`) ตาม Figma 1:5323 และ 1:5408 กล่องที่เห็นอยู่กลางกรอบ (checkbox 14 / 17.5 / 21px เว้นรอบละ 3 / 3.25 / 3.5px, radio 16 / 20 / 24px เว้น 2px) ข้อความห่างกรอบ 8px และอยู่กึ่งกลางแนวตั้งกับกรอบ (เดิมจัดตามเส้นฐาน กล่องสูงกว่ากึ่งกลางข้อความ 1 ถึง 4px)
- พื้นที่คลิกเท่ากรอบ (input โปร่งใสเต็มกรอบ) เดิมเท่ากล่องที่วาด
- ตาราง (คอลัมน์ checkbox) ใช้กรอบ 20px ตาม Figma ต่อไป; Tree ใช้กรอบ 24px ของตัวเองเหมือนเดิม

## ผลต่อแอปที่ใช้อยู่
- แถวที่มี checkbox / radio กว้างและสูงขึ้นเล็กน้อย: ปกติ 17.5 → 24px, small 14 → 20px, large 21 → 28px ต่อกรอบ (ความกว้างของ label รวมกรอบเพิ่ม 6.5 / 6 / 7px) ข้อความขยับขวาตามนั้น และ label ขยับแนวตั้งเข้าสู่กึ่งกลางกล่อง
- ความสูงของตัวห่อ: ปกติ 24, small 22, large 28 (เดิมได้ 23.5 / 22 / 27 สำหรับ checkbox และ 26 / 22 / 30 สำหรับ radio)

## ตรวจแล้ว
- วัดกรอบ ระยะกล่องในกรอบ ช่องว่างถึงข้อความ และการจัดกึ่งกลางกับข้อความ ได้ค่าเดียวกันทุกตัวบน 18.2.1, 19.3.1, 20.4.4, 21.3.3, 22.1.2 (checkbox ทั้ง 7 แบบ และ radio ทั้ง 4 แบบ รวมแบบเลือก, indeterminate, error, disabled)
- ดูภาพ render: เครื่องหมายถูก, สี่เหลี่ยม indeterminate และวงแหวนยังอยู่กลางกล่อง
- หน้าเว็บ (22.1.2): หน้า Checkbox/Radio ได้กรอบ 24 / 20 / 28, หน้า Table ได้กรอบ 20 และหัวตารางยังสูง 48 ไม่มี error ไม่ล้นจอ
- ยังไม่ได้วัด: checkbox ที่อยู่ใน Tree select, Menu หรือฟอร์มจริงของแอป Ai-BOX
