# v0.53.8 – แผงเวลา, รายการ Select small และรายละเอียดเล็ก (ชุดที่ 3 ของรายงานเทียบเว็บ)
วันที่: 2026-11-26

## แก้ไข
- แผง Time picker ได้ 125 × 290 ตาม Figma (1612:3689): padding บน 10px (เดิมถูก ng-zorro 22 ทับเหลือ 4px), คอลัมน์กว้าง 62.5 สูง 224 เริ่มที่ y=10, เส้นคั่นคอลัมน์ `rgba(0,0,0,.06)` (สี colorsplit ของ Figma; ไม่มี token), ไม่มีเส้นเหนือปุ่ม, ส่วนปุ่มสูง 56 (เดิม 59: เส้นล่าง 1px + line box 34px ของ ng-zorro), ปุ่ม 101 × 32 ที่ x=12
- Select small: เพิ่ม class `aibox-select-dropdown--small` (ใส่ผ่าน `nzDropdownClassName`) แถวสูง 40, padding 8/16, 14/24 ตาม Figma dropdown size=small
- Tag Selection: กล่องสูงสุดเริ่มต้นของ `aibox-select-scroll` เป็น 420px (Figma column view = 456 รวม label 32 + 4 + กล่อง 420; เดิมใช้ 456 ที่กล่อง)
- Tag checkable: ไอคอนนำหน้ามีกล่อง 16 × 16 (glyph 12px) และสีไอคอนตอนเลือก + disabled เป็น `text/icon-default` (เขียนตามสเปก Figma ยังไม่ได้วัดในเบราว์เซอร์)

## เอกสาร
- หน้า Select: demo "Small list", ตาราง Class เสริมมีแถวใหม่, แก้ 456 เป็น 420
- หน้า Time picker: ปุ่มท้ายแผงใน Figma เขียน "เลือก" แต่ข้อความมาจาก locale: ตั้ง `provideNzConfig({ timePicker: { nzOkText: 'เลือก' } })`
- หน้า Message: snackbar ถูกย้ายไป Archived ใน Figma ให้ใช้ alert-bar แบบลอยแทน (`aibox-snackbar-*` ยังใช้ได้ แต่ถือว่าเลิกใช้)

## ตรวจแล้วและไม่แก้
- T37 (ไอคอนในแท็บ card): วัดบน 22.1.2 แล้ว ตัวไอคอน 12px อยู่ที่ x=34 และข้อความอยู่ที่ x=56 = 32 + 24 ซึ่งตรงกับ Figma (กล่อง 16 + ห่าง 8) ข้อความไม่ได้เลื่อนไปซ้าย
- T41 (กล่อง icon ใน avatar): glyph 12px อยู่กลางกล่อง 16 อยู่แล้วเมื่อมองด้วยตา จึงไม่แก้
