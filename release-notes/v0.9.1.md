# v0.9.1 – Select icons centred
วันที่: 2026-11-04

## แก้ไข
- ไอคอนลูกศร (และไอคอน clear / search ตอนเปิด) ของ `nz-select` อยู่กึ่งกลางแนวตั้งแล้ว: เดิมต่ำกว่ากลาง 4px เพราะ ng-zorro กำหนดความสูงให้ host (32 / 40px) และวางไอคอนที่ 50% ของ host ส่วน override ขยายแค่ตัว selector (40 / 48px) ตอนนี้ host สูงเท่ากับ selector ทุกขนาด (default 40, large 48, `nzSize="small"` 40)
- ตรวจกับ ng-zorro-antd 22.1.2 (DOM จริงจากเว็บ docs): ปกติ, large, search ตอนเปิด, error, disabled และไอคอน clear ได้ค่ากึ่งกลางเป๊ะ (0px)

## ที่ต้องรู้ก่อนอัปเกรด
- dropdown ของ select ห่างจากกล่อง 4px (ค่ามาตรฐานของ ng-zorro วัดจริงบน 22.1.x ส่วน 18.2.x ค่า margin ของ ant เองคือ 4px แต่ยังไม่ได้วัดระยะจริง) เดิมคำนวณจาก host ที่เตี้ยกว่าเลยดูซ้อนกล่อง; ลบ margin 2px ที่เคยเพิ่มไว้ออกแล้ว ควรให้ designer ยืนยันระยะห่างที่ต้องการ
- host ของ `nz-select` สูงขึ้นเป็น 40 / 48px: ถ้าโปรเจ็คจัด layout โดยอาศัยความสูง 32px เดิม ให้ตรวจ

## ยังไม่ครอบคลุม
- Input ที่มีไอคอน (`nz-input-group` prefix / suffix): override ยังไม่ครอบคลุม จึงไม่ได้แก้ตรงนั้น
