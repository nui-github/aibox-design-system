# v0.43.0 – Dropdown menu กว้างเท่าแถวที่ยาวที่สุดทุกเวอร์ชันของ ng-zorro-antd
วันที่: 2026-11-23

## แก้ไข
- Dropdown menu (`nz-dropdown` + `nz-menu`): override ตั้ง `.ant-dropdown { width: auto }` แผงเมนูจึงกว้างตามแถวที่ยาวที่สุด (Figma popover-submenu 214 / 265px) ทุกเวอร์ชัน เดิม ng-zorro-antd 18 และ 19 ตั้งความกว้างเมนูเท่าปุ่มที่กด (ปุ่มกว้าง 320px ได้เมนูกว้าง 320px) ส่วน 20 ขึ้นไปห่อตามเนื้อหา
- ผลต่อผู้ใช้ 18 / 19: เมนูแคบลงจากเท่าปุ่มเป็นเท่าเนื้อหา (ปุ่ม "Open menu" 114.8px: เมนู 114.8px เป็น 101.6px) ผู้ใช้ 20 / 21 / 22 ไม่เห็นการเปลี่ยนแปลง
- ตารางเวอร์ชันที่รองรับ (หน้า Getting started) และ README: เอาหมายเหตุ "Dropdown menu กว้างกว่า" ของ 19.3.1 ออก และระบุสิ่งที่ยังต่างอยู่คือระยะห่างระหว่างปุ่มกับเมนู (18 / 19 = 6px, 20+ = 4px)

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปเล็กที่มีแค่ Dropdown พร้อม CSS ของ release นี้) ได้ค่าเท่ากัน: ปุ่ม 114.8px ได้เมนู 101.6px, ปุ่ม 320px ได้เมนู 95.1px ก่อนแก้ 18 / 19 ได้ 114.8px และ 320px
- `npm test` ผ่าน (846 token)

## ยังไม่ครอบคลุม
- ระยะห่างระหว่างปุ่มกับเมนู ยังเป็นค่าของ ng-zorro (18 / 19 = 6px, 20+ = 4px)
- submenu ซ้อน, ไอคอนในแถว, แถว danger / disabled
