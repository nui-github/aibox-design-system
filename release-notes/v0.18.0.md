# v0.18.0 – Empty
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ `nz-empty` ตาม Figma หน้า Empty State (Empty `917:5774`): ถาด 64×40, ระยะห่างภาพกับข้อความ 8px, ข้อความ 16/26 สี `text/icon-default` (เทาอ่อนเดียวกับภาพ), ไม่มี margin ภายนอก
- `aibox-empty-lg` สำหรับ variant image big (ถาด 128×80)
- variant icon: ส่ง template ที่มีไอคอนเป็น `nzNotFoundImage` ไอคอนแสดง 24px
- หน้า Empty ในเว็บเอกสาร (route `/empty`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| variant default | `<nz-empty nzNotFoundImage="simple" nzNotFoundContent="Empty">` |
| variant image big | เพิ่ม class `aibox-empty-lg` |
| variant icon | `[nzNotFoundImage]` เป็น template ที่มี `<nz-icon>` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-empty` ทุกตัวเปลี่ยนหน้าตา: ข้อความ 16px สีเทาอ่อน (#bbbec4) และ margin ภายนอกเป็น 0 (ng-zorro เดิมมี 32px ในแบบ normal)
- ภาพ default ของ ng-zorro (ถาดใหญ่ 184×152) จะถูกย่อเป็นสูง 40px เพราะ Figma ใช้ภาพแบบ simple; ให้ใส่ `nzNotFoundImage="simple"`

## ยังไม่ครอบคลุม
- "Empty Content" (การ์ดที่มีไอคอน ข้อความ และปุ่ม) ต้องรอ override ของ Card
- dark theme
