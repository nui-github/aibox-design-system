# v0.33.0 – Input number
วันที่: 2026-11-17

## เพิ่มใหม่
- `nz-input-number` ใช้สไตล์เดียวกับ Input ใน Figma (ไม่มี input-number ใน Figma จึงอิงจาก textfield): กล่องสูง 40px (`nzSize="large"` 48px), ขอบ 1px `state/form/default`, มุม 4px, ตัวอักษร 14/24 (large 16/26), padding 8 / 12, placeholder `text/placeholder`
- สถานะ hover / focus (วงนอก 2px) / error (`nzStatus="error"`) / disabled / `nzBorderless` เหมือน Input
- ปุ่มเพิ่ม/ลด (ขึ้นตอน hover) ใช้โครงของ ng-zorro (กว้าง 22px ลูกศร 7px) เปลี่ยนเฉพาะสีเส้นกับสีไอคอน (`state/gray/g-6`, hover `color/main`) เพราะไม่มีใน Figma
- เว็บเอกสาร: demo "Input number" ในหน้า Input (ขนาดปกติ, large, error, disabled)

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1 และ 22.1.2 ได้ค่าเท่ากัน: กล่อง 40 / 48px ขอบ `#e4e5e7` มุม 4px, error ขอบ `#f25c5a`, disabled พื้น `#f1f2f3`

## ยังไม่ครอบคลุม / คำถามถึง designer
- ไม่มีใน Figma: ขนาดและหน้าตาของปุ่มเพิ่ม/ลด, input-number ที่มี prefix / suffix / addon (`nz-input-number-group`)
