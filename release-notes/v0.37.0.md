# v0.37.0 – Tag แบบมีปุ่ม close
วันที่: 2026-11-18

## เพิ่มใหม่
- Tag แบบมีปุ่ม × (Figma tag/closable, node `1:10102`): `<nz-tag nzMode="closeable">` สีเหมือน badge (ปกติ, `processing` = น้ำเงิน, `success`, `warning`, `error`, `purple`) บวก class `aibox-tag-black` (เทาเข้ม `state/gray/g-1` ตัวอักษรขาว)
- ขนาดปกติ = Figma small (ตัวอักษร 14px, padding 8 12, สูง 32px); ใส่ `aibox-tag-xs` = 2xsmall (12px, padding 4 8, สูง 24px); `aibox-tag-square` (มุม 4px) ใช้ร่วมได้
- ปุ่ม × และไอคอนนำหน้า (`<span nz-icon>` หน้าข้อความ) เป็นกล่อง 16px ไอคอน 12px ห่างข้อความ 4px (ng-zorro ใส่ 7px หลังไอคอนนำหน้า ตอนนี้ตั้งเป็น 0)
- Tag สีน้ำเงินแบบ closable ใช้ `text/main` ตาม Figma (badge สถานะใช้ info-200)
- เว็บเอกสาร: demo "Closable" (7 สี) และ "Closable: x-small, square, icon" ในหน้า Tag, แถว `aibox-tag-black` ในตารางคลาสหน้า Getting started

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1, 20.4.4 และ 22.1.2 ได้ค่าเท่ากัน: ขนาดปกติ 66.7 x 32px, xs 55.7 x 24px, xs + ไอคอนนำหน้า 75.7 x 24px (Figma 76 x 24), small + ไอคอน 86.7 x 32px (Figma 87 x 32), สีพื้นและตัวอักษรตรงตาม token ของ Figma

## ยังไม่ครอบคลุม
- Closable แบบ "naming" (มีรูปคน), สถานะ hover ของปุ่ม × (ไม่มีใน Figma จึงไม่เปลี่ยนสี)
