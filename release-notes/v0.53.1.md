# v0.53.1 – Collapse ตรงตาม Figma (ไม่มีกรอบนอก) และ Card ลด padding 1px
วันที่: 2026-11-25

## แก้ไข
- Collapse (v0.50.0) ทำกรอบนอก 1px มุม 8px ให้ Basic และเนื้อหา padding 16 ซึ่งไม่มีใน Figma: ตรวจซ้ำกับหน้า Collapse (`1105:1930`) แล้ว Basic ไม่มีกรอบ มีแค่เส้น 1px ใต้หัวข้อ (เส้นอยู่ "ข้างใน" ความสูง 48px จึงลด padding ล่างเหลือ 11px) และเนื้อหาเป็น Collapse Content List (padding 8, ข้อความเริ่มห่างขอบ 32px) สูง 40px สำหรับหนึ่งบรรทัด (Figma: ขยายแล้ว 88px = 48 + 40)
- Borderless: ไม่มีเส้นใต้หัวข้อ เนื้อหา padding 16 และมีเส้น 1px ปิดท้ายเมื่อเปิด (Figma: สองบรรทัด 128px); Ghost: ไม่มีเส้น เนื้อหาเริ่มห่างขอบ 32px เหมือน Basic; แถว disabled ของ Ghost เป็นตัวอักษรจางอย่างเดียว ไม่มีพื้นเทา (Basic / Borderless ยังเป็นพื้น `bg/disable`)
- Card (`nz-card`): เนื้อหา padding 24 / 16 นับจากขอบนอกตาม Figma (เส้นขอบ 1px อยู่ข้างใน) แต่เดิมนับหลังเส้นขอบ ทำให้ข้อความและปุ่มในการ์ดห่างขอบมากกว่า Figma 1px ทุกด้าน: ตอนนี้ padding จริง 23 / 15px (วัดจาก Figma Card / Advanced `4065:7590`: เนื้อหาเริ่มที่ x=16, y=24 จากขอบนอก) การ์ดแบบ Card Menu (`aibox-card-menu`, ไม่มีเส้นขอบ) ไม่เปลี่ยน
- ขนาด small = 40px, default = 48px, large = 58px (ลดเส้นล่างจาก padding ล่าง 1px เหมือนกัน)
- เว็บเอกสาร: คำอธิบายของ demo ในหน้า Collapse ปรับให้ตรง
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): ความสูงหัวข้อ ตำแหน่งลูกศร / ข้อความ / เนื้อหาเท่ากันทุกเวอร์ชัน

## หมายเหตุ
- เป็นการเปลี่ยนหน้าตาของ Collapse ที่ใช้ v0.50.0 ถึง v0.53.0 อยู่ (กรอบนอกหาย เนื้อหากระชับขึ้น) ถ้าแอปต้องการกรอบ ให้ใส่เองที่ element ที่ครอบ
