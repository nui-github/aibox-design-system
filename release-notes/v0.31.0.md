# v0.31.0 – Input / Select options (textarea, search, password, multiple)
วันที่: 2026-11-17

## เพิ่มใหม่
- Select แบบเลือกหลายค่า (`nzMode="multiple"` / `"tags"`) ตาม Figma Tag Selection (`3959:10071`): กล่องสูงขึ้นตามแท็ก (แถวเดียว = 40 / 48px, สองแถว = 72 / 80px), แท็กขึ้นบรรทัดใหม่ห่างกัน 8px, แท็ก 24px พื้น `bg/secondary` มุม 4 ตัวอักษร 12/16 medium ปุ่ม × 12px
- Textarea ตาม Figma (`1:7232`): เริ่มสูง 80px (`nzSize="large"` 96px) ขยายแนวตั้งได้ padding 8 / 12 และ line-height 24 / 26; `nz-textarea-count` แสดงตัวนับใต้กล่อง ชิดขวา
- Input แบบมี prefix / suffix (`nz-input-group` ใน 18, `nz-input-wrapper` ใน 22) ใช้กรอบเดียวกับ Input: ขอบ มุม hover / focus / error / disabled และขนาด large 48px
- Search (`1:7587`): class `aibox-search` กล่อง 40px (large 48px) ไอคอน 16px; ปุ่ม × ของ `nzAllowClear` (ng-zorro 22) เป็นกากบาทเรียบแทนวงกลมทึบ
- Password (`6581:98500`): ไอคอนตาท้ายกล่อง 16px สี `state/gray/g-6`
- ข้อความช่วย (`1:7499`): `nzExtra` 14/24 `text/secondary`, `nzErrorTip` สี error พร้อมไอคอน; class `aibox-form-small` บน `nz-form-item` = ตัวอักษร 12/22 (Figma size small)
- เว็บเอกสาร: demo ใหม่ในหน้า Input (Textarea, Textarea with count, Prefix and clear, Search, Password, Assistive text) และหน้า Select (Multiple and tags), ไอคอนตา, แถว `aibox-search` / `aibox-form-small` ในตารางหน้า Getting started

## แก้ไข (พบจาก audit บน ng-zorro-antd 18.2.1)
- Select แบบหลายค่าเดิมสูงคงที่ 40px ทำให้แท็กที่ขึ้นบรรทัดใหม่ล้น/ถูกตัด
- `nz-input-group` / `nz-input-wrapper` แบบ large สูง 63px (ควร 48px) เพราะ input ข้างในยังมี min-height 48px
- `nzBorderless` ของ Input ยังแสดงขอบ
- line-height ของ textarea เป็น 22px (ค่า Ant) แทน 24 / 26px
- CSS `min-height` บน textarea ทำให้ `nzAutosize` วัดแถวผิด จึงใช้เฉพาะ textarea ที่ไม่มี `rows`

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1 และ 22.1.2 ได้ค่าเท่ากัน (textarea 80 / 96, search 40 / 48, password 48, tag 24, multiple 40 / 48 / 72 / 80, ข้อความช่วยห่างกล่อง 4px)

## ยังไม่ครอบคลุม / คำถามถึง designer
- ไม่มีใน Figma: `nz-input-number`, addon ก่อน/หลัง, compact group, OTP, `nzStatus="warning"` (ยังเป็นสี Ant), ตัวนับที่เปลี่ยนเป็นสีแดงเมื่อเกินกำหนด, แท็กตอน disabled (ใช้พื้นขาวตัวอักษร `text/disable` เป็นค่าอนุมาน), hover ของปุ่ม × ในแท็ก
- ยังไม่ทำ: Tag Selection แบบ column / list view และ panel ตอนพิมพ์ / แนะนำ
- พบความไม่ตรง (ยังไม่แก้ เพราะเปลี่ยนหน้าตา Input ทุกที่): Input ขนาดเริ่มต้นสูง 34px แต่ Figma small สูง 40px (Select เริ่มต้น 40px อยู่แล้ว); label เริ่มต้น 14/24 แต่ Figma small เป็น 12/22
