# v0.27.0 – Cascader
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ dropdown ใน `nz-cascader` ตาม Figma หน้า Cascader (Cascader Dropdown `4268:12892`, Cascader Containment `4268:13151`): พื้น `bg/primary` มุม 4px เงา `0 4px 4px / 0 -1px 4px` (token ใหม่ `--aibox-cascader-menu-shadow`) ไม่มี padding รอบเมนู คอลัมน์แต่ละระดับคั่นด้วยเส้น 1px สี `border/primary`
- แถว (`content-list`): padding 12×16 ข้อความ 16/26 สี `text/primary` เส้นล่าง 1px, ไอคอนลูกศรขยายสี `text/icon-default`, แถวที่ disabled สี `text/disable`
- hover และแถวของเส้นทางที่เปิดอยู่: พื้น `bg/tertiary` ตัวอักษร `color/main` (แถวที่เปิดอยู่ใช้น้ำหนัก medium)
- ช่องของ cascader (`.ant-select`) ใช้สไตล์ Select เดิม: ใช้ `nzSize="large"` และ `[nzShowSearch]="true"` ให้ได้ไอคอนค้นหา
- หน้า Cascader ในเว็บเอกสาร (route `/cascader`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| ช่อง (size large, search icon) | `<nz-cascader nzSize="large" [nzShowSearch]="true">` |
| Cascader Dropdown column 1 / 2 / 3 | คอลัมน์ของเมนูตามระดับของ `nzOptions` |
| content-list | `.ant-cascader-menu-item` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-cascader` ทุกตัวเปลี่ยนหน้าตา: แถวสูงกว่าเดิม (50px) พื้นเมนูไม่มีขอบใน และความสูงเมนูสูงสุด 300px
- `nzShowSearch` ใน ng-zorro 22 รับค่า boolean หรือ object (ต้องเขียน `[nzShowSearch]="true"`)
- สี hover / เส้นทางที่เปิดอยู่ (`bg/tertiary` + `color/main`) ผมกำหนดเอง เพราะ Figma ไม่แสดงสถานะเหล่านี้ (ใช้ชุดเดียวกับ Tree) ควรให้ designer ยืนยัน

## ยังไม่ครอบคลุม
- แถวสองบรรทัดของเฟรม Figma (ไอคอนซ้าย + หัวข้อ + คำอธิบาย 14/24 สี `text/tertiary`, สูง 74px): `nz-cascader` มีแค่ป้ายข้อความ ต้องทำเองด้วย `nzOptionRender`
- ข้อความ "ไม่พบ" (notfound), โหมด multiple / checkbox
