# v0.47.6 – Date picker และ Time picker: กล่องและข้อความตรงกับ Figma
วันที่: 2026-11-23

## แก้ไข
- ความสูงขนาดเริ่มต้น: Date picker และ Time picker (ไม่ใส่ `nzSize`) สูง 34px ทุกเวอร์ชัน Figma (date-picker `1347:23603`, time-picker `1612:3566`) ใช้กล่อง textfield ขนาด small สูง 40px เหมือน Input เพิ่ม `min-height` ของกล่องเป็น 40px (large ยัง 48px)
- ตำแหน่งข้อความ: เริ่มที่ 8px (large 12px) จากขอบซ้ายของกล่อง ตาม Figma เดิม 9px / 13px (กรอบ 1px บวก padding) ลด padding แนวนอนเหลือ 7px / 11px เหมือน Input (v0.47.5)
- ไอคอนปฏิทิน / นาฬิกา: ห่างขอบขวา 10px (large 14px) ตาม Figma (ไอคอน 16px ในกล่อง 20px ที่ห่างขอบ 8px / 12px) เดิม 9px / 13px เพิ่ม `margin-inline-end: 2px` ให้ `.ant-picker-suffix`
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก) และหน้าเว็บเอกสารบน 22.1.2 (รวม range picker): กล่อง 40px / 48px, ข้อความเริ่มที่ 8px / 12px, ไอคอนห่างขอบขวา 10px / 14px และอยู่กึ่งกลางแนวตั้ง เท่ากันทุกเวอร์ชัน

## หมายเหตุ
- Select ตรงกับ Figma อยู่แล้ว (select `1:7137`): ข้อความเริ่มที่ 8px / 12px ลูกศรห่างขอบขวา 10px / 14px กึ่งกลางแนวตั้ง บน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 จึงไม่ได้แก้
- Figma ของ Select small วางลูกศรสูงกว่ากึ่งกลาง 2px (y=8 ในกล่อง 40px) เหมือน Password small ขณะที่ Date picker / Time picker small อยู่กึ่งกลาง จึงเลือกกึ่งกลางทุกชิ้น ควรให้นักออกแบบยืนยัน
- กล่อง Date picker ที่เคยสูง 34px จะสูงขึ้น 6px ในหน้าที่ใช้ขนาดเริ่มต้น
