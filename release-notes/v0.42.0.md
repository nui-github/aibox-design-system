# v0.42.0 – Tree: แถวห่างกัน 42px ทุกเวอร์ชันของ ng-zorro-antd
วันที่: 2026-11-19

## แก้ไข
- Tree (`nz-tree`): override รีเซ็ต `margin` ของแถวเป็น 0 แถวจึงติดกันและห่างกัน 42px (ตามความสูงแถวใน Figma) ทุกเวอร์ชันของ ng-zorro-antd เดิม 21 / 22 เพิ่ม `margin-bottom: 4px` ให้แถว ทำให้ห่างกัน 46px ส่วน 18 / 19 / 20 ห่างกัน 42px
- ผลต่อผู้ใช้ 21 / 22: Tree แน่นขึ้นแถวละ 4px (ค่าเดิม 46px) ผู้ใช้ 18 / 19 / 20 ไม่เห็นการเปลี่ยนแปลง
- ตารางเวอร์ชันที่รองรับ (หน้า Getting started) ตัดหมายเหตุ Tree ของ 19.3.1 และ 20.4.4 ออก เพราะไม่ต่างแล้ว README ปรับข้อความตามนี้

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 ได้ค่าเท่ากัน: `margin` ของแถว 0, แถวสูง 42px ห่างกัน 42px ทุกแถว, tree ใน demo สูง 252px (เดิมบน 21 / 22 เป็น 272px)
- `npm test` ผ่าน (846 token)

## ยังไม่ครอบคลุม
- รายการ tree ใน `nz-tree-select` (ไม่มีกฎของ override) และ Tree แบบ draggable / line / block-node
