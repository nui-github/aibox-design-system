# v0.29.0 – Menu
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ `nz-menu` แบบ `nzMode="inline"` ตาม Figma หน้า Navigation (เมนูแนวตั้ง `154:3272`: แถว Default / Menu Expand / Submenu)
- แถวกลุ่ม (`nz-submenu` หรือ `nz-menu-item` ระดับบน): padding 16, ข้อความ 14/24 สี `text/tertiary`, เส้นล่าง 1px และเส้นขวาของเมนู 1px สี `text/white/secondary`, พื้น `bg/primary` กว้าง 240px
- แถวที่เปิด (`nzOpen`): ข้อความ `color/main` น้ำหนัก medium และลูกศรชี้ลง (ปิด = ลูกศรชี้ขวา สีเทา)
- รายการย่อย (`nz-menu-item` ใน submenu): 208×32 padding 4×16 มุม 4px ห่างกัน 8px และท้ายกลุ่มเว้น 24px; hover พื้น `component/bg/bg-active` ตัวอักษร `color/main` medium; เลือกอยู่ (`nzSelected`) พื้น `bg/main` ตัวอักษรขาว medium
- หน้า Menu ในเว็บเอกสาร (route `/menu`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| แถวกลุ่ม (Default / Menu Expand) | `<li nz-submenu nzTitle>` |
| Menu Expand (เปิด) | `nzOpen` |
| รายการย่อย Default / Hover / Active | `<li nz-menu-item>` / hover / `nzSelected` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-menu` แบบ inline ทุกตัวเปลี่ยนหน้าตา: แถวสูง 56px (เดิม 40px) ไม่มีแถบสีข้างรายการที่เลือก และพื้นของเมนูย่อยโปร่งใส
- ng-zorro ใส่ `padding-inline-start` ตามระดับ (24 / 48px) เป็น inline style override จึงใช้ `!important` เฉพาะ `padding-inline-start` ของหัวข้อและรายการย่อย เพื่อให้ได้ 16px ตาม Figma
- ลูกศรเป็นลูกศรของ ng-zorro (CSS) หมุนให้ชี้ขวา/ลงตาม Figma ไม่ใช่ glyph ของ Font Awesome

## ยังไม่ครอบคลุม
- เมนูแบบยุบ (เหลือแต่ไอคอน), ไอคอนหน้าแถว, เมนู horizontal / popup, dark theme, รายการ danger / disabled, สถานะ hover ของแถวกลุ่ม (Figma ไม่แสดง ตอนนี้เปลี่ยนเป็นสี `color/main`)
- Sidebar (`7678:58099`), Header (`3912:18199`), Menu Product, Mobile header, Inbox list ในหน้า Navigation เป็นโครงของแอป ไม่ได้ override
