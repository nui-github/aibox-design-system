# v0.41.2 – ng-zorro-antd 19.3.1 และ 21.3.3 ตรวจครบทุก component
วันที่: 2026-11-18

## แก้ไข
- ตารางเวอร์ชันที่รองรับ (หน้า Getting started) และ README: 19.3.1 และ 21.3.3 เปลี่ยนจาก "ตรวจแล้วบางส่วน" เป็น "ตรวจแล้ว"
- แก้ข้อมูลของ 20.4.4: Tree แถวห่างกัน 42px (21 / 22 = 46px) ซึ่งตกหล่นตอนตรวจครั้งก่อน
- ไม่มีการเปลี่ยน CSS หรือ token (ไฟล์ `dist/` เหมือน v0.41.1 ยกเว้นเลขเวอร์ชัน)

## ตรวจแล้ว
- 21.3.3: เว็บเอกสารทั้งเว็บ build ผ่าน, demo ทุกหน้า (27 หน้า) และสคริปต์วัด overlay 18 ตัวได้ค่าเท่ากับ 22.1.2 ทุกค่า (ต่างแค่ API: `nzBorderless` ใช้ไม่ได้แล้ว)
- 19.3.1: ได้ค่าเท่ากับ 22.1.2 ยกเว้นค่าเริ่มต้นของ ng-zorro เอง: Dropdown menu 124.9px (92.8px), Pagination size changer กว้างกว่า 3px, กล่องลูกศร Tooltip 22px (16px, ศูนย์กลางเท่าเดิม), Tree แถวห่าง 42px (46px) เว็บเอกสารรันบน 19 ไม่ได้ จึงใช้สำเนาที่ปรับ API
- Tree: ng-zorro 21 ขึ้นไปเพิ่ม `margin-bottom: 4px` ให้แถว (46px บน 21 / 22, 42px บน 18 / 19 / 20) override กำหนดความสูงแถว 42px แต่ไม่ได้กำหนดระยะห่าง
- ตรวจพบว่าสำเนาทดสอบของ 18 และ 20 ใช้ `tokens.css` เก่า จึงอัปเดตแล้ววัดซ้ำ ผลบน 18 / 20 ไม่เปลี่ยนจากที่รายงานไว้ (ยกเว้น Tree ข้างบน)
