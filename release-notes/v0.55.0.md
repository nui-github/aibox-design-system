# v0.55.0 – ชุดที่ 5: หัวปฏิทิน, เมนูคำสั่ง 216px, tag-round (คำตอบข้อที่ต้องถาม)
วันที่: 2026-11-26

ชุดนี้ทำตามคำตอบของคุณในข้อ T43, T47, T51, B3 ของรายงาน

## ใหม่
- หัวปฏิทิน (T47): เดือนขึ้นก่อนปี ("พฤศจิกายน 2026") ด้วย CSS ตรวจลำดับและระยะห่าง 8px บน 18.2.1, 19.3.1, 20.4.4, 21.3.3, 22.1.2 (แอปทดสอบเป็นภาษาอังกฤษ "Nov 2026") ชื่อเดือนเต็มต้องมาจาก locale ของแอป: `monthFormat: 'MMMM'` (โค้ดอยู่ในหน้า Getting started และ README) เว็บเอกสารตั้งค่านี้แล้ว วัดบน 22.1.2 ได้ "พฤศจิกายน" ก่อนปี
- `aibox-tag-round` (B3): ชื่อ class ของทรงแคปซูล (= ค่าเริ่มต้นเดิม) ใช้เขียนให้ชัดใน markup ค่าเริ่มต้นของ tag ยังเป็นแคปซูลเหมือนเดิม จึงไม่มี tag ของแอปที่ใช้อยู่เปลี่ยนหน้าตา

## แก้ไข
- เมนูคำสั่ง (T51): `aibox-dropdown-actions` กว้างอย่างน้อย 216px ตาม Figma dropdown-menu (เดิมกว้างเท่าข้อความยาวสุด) วัดได้ 216 × 182 (3 แถวสูง 50) บน 22.1.2 ข้อความยาวกว่ายังดันกล่องให้กว้างขึ้นได้ ค่าเริ่มต้นของ `nz-dropdown` ยังเป็น popover-submenu (รอ designer F16)

## เอกสาร
- Time picker (T43): บอกชัดว่าแบบมือถือของ Figma (แผงกว้างเท่าช่อง) ไม่รองรับ แผงกว้าง 125px ทุกขนาดจอ
- ค่าเริ่มต้นของ tag ใน Figma เป็น square แต่ override คงแคปซูลไว้เพื่อไม่ให้แอปเดิมเปลี่ยน ฝั่ง toey ตั้ง square เป็นค่าเริ่มต้น ถ้าแอปใช้สองชุดต้องใส่ class ให้ชัด (`aibox-tag-square` หรือ `aibox-tag-round`)

## หมายเหตุ
- เมนูคำสั่ง 216px วัดบน 22.1.2 เท่านั้น
