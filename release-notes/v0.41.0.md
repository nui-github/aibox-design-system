# v0.41.0 – Tag Selection: มุมมองคอลัมน์ / รายการ และกล่องเลื่อนได้
วันที่: 2026-11-18

## เพิ่มใหม่
- `aibox-select-list` (ใช้คู่กับ `aibox-select-naming`): มุมมองรายการของ Figma Tag Selection (node `4476:2990`) หนึ่งแท็กต่อบรรทัด กว้างเต็มกล่อง ชื่อดันปุ่ม × ไปชิดขวา ชื่อยาวตัดด้วย … ถ้าไม่ใส่ = มุมมองคอลัมน์ (node `4475:1852`) ที่แท็กเรียงต่อกันเหมือนเดิม
- `aibox-select-scroll`: กล่องหยุดโตที่ 456px (ปรับด้วย `style="--_select-max-h: 340px"`) แล้วเลื่อนในกล่อง scrollbar กว้าง 4px ราง `bg/secondary` แถบ `text/tertiary` ตาม Figma scrollbar-Vertical
- เว็บเอกสาร: demo "Tag Selection views" (หน้า Select) และแถวคลาสใหม่ในหน้า Getting started

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 22.1.2: มุมมองคอลัมน์ 724px แท็ก 30px เรียงหลายแถว, มุมมองรายการแท็ก 672 x 30px ชื่อ 602px, กล่องที่ตั้งสูงสุด 340px เลื่อนได้ (เนื้อหา 434px) ภาพตรงกับ Figma
- `npm test` ผ่าน (846 token)
- ยังไม่ได้วัดซ้ำบน 18.2.1 / 20.4.4 (โครงสร้าง DOM ของ Select หลายค่าเหมือนที่ตรวจไว้ใน v0.40.0)
