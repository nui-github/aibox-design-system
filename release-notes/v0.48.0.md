# v0.48.0 – Tree select: รายการในกล่องใช้แถวเดียวกับ Tree ตาม Figma
วันที่: 2026-11-24

## แก้ไข
- รายการต้นไม้ใน `nz-tree-select` (dropdown): กฎของ Tree ไม่เคยถูกใช้กับรายการนี้เลย เพราะรายการใน `nz-tree-select` ใช้คลาส `ant-select-tree-*` ไม่ใช่ `ant-tree-*` แถวจึงเป็นของ ng-zorro (สูง 24px บน 20.4.4 / 21.3.3 / 22.1.2 และ 28px บน 18 / 19 ลูกศรกว้าง 24px checkbox 16px) ทั้งที่ release notes ของ v0.26.0 ระบุว่าครอบคลุมแล้ว เพิ่มตัวเลือก `.ant-select-tree` ให้กฎทุกข้อของ Tree: แถวสูง 42px ลูกศรกล่อง 20px ที่ 8px เยื้องระดับละ 24px (ระดับแรก 32px) checkbox 17.5px ข้อความ 16/26 hover และ selected เหมือน Tree ตาม tree-selection-list (`9718:69790`)
- Tree (`nz-tree` และรายการใน `nz-tree-select`) ที่มี checkbox: ข้อความเริ่มที่ 68px (ระดับ 1) ตาม Figma เดิมเริ่มที่ 61.5px เพราะ checkbox ใน Figma อยู่ในกรอบ 24px (กล่อง 17.5px อยู่กึ่งกลาง ห่างขอบ 3.25px) แล้วห่าง 8px ถึงชื่อ override ใช้ margin `3.25px` ซ้ายและ `11.25px` ขวา กล่อง checkbox จึงเริ่มที่ 39.25px ตรงกับ Figma (ต้นไม้ที่ไม่มี checkbox ไม่เปลี่ยน: ข้อความเริ่มที่ 36px)
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): แถวสูง 42px ห่างกัน 42px ลูกศรที่ 8 / 40 / 64 / 88 / 112px (ระดับ 1–5) checkbox ที่ 39.3px ข้อความที่ 68px (ระดับ 1) ทั้งใน `nz-tree` และ `nz-tree-select` เท่ากันทุกเวอร์ชัน
- เว็บเอกสาร: หน้า Tree มี demo "Tree select" (`nz-tree-select` พร้อม `nzCheckable`) วัดแล้วบน 22.1.2

## หมายเหตุ
- กล่องของ `nz-tree-select` ที่ปิดอยู่เป็นช่อง Select (ข้อความ 8px / 12px ตาม Figma select) ตรวจแล้วใน v0.47.x
- หน้า dropdown ที่ใช้ virtual scroll (`nzVirtualHeight` ฯลฯ) ใช้ความสูงต่อแถว `nzVirtualItemSize` (ค่าเริ่มต้น 28): ถ้าเปิด virtual scroll ต้องตั้ง `[nzVirtualItemSize]="42"` เหมือน `nzOptionHeightPx` ของ Select (ยังไม่ได้ทดสอบกรณีนี้)
- สี hover / selected ยังเป็นค่าที่อ่านจากเฟรม Folder-list ไม่ใช่ tree-selection-list (เหมือนเดิม) ควรให้นักออกแบบยืนยัน
