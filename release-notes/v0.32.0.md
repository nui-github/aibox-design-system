# v0.32.0 – Input ขนาดเริ่มต้นสูง 40px
วันที่: 2026-11-17

## แก้ไข
- Input ขนาดเริ่มต้น (และ `nzSize="small"`) สูง 40px ตาม Figma textfield Size=small (เฟรม `5330:5582` สูง 92 = label 22 + 4 + กล่อง 40 + 4 + ข้อความช่วย 22) จากเดิม 34px ทำให้เท่ากับ Select ขนาดเริ่มต้น (40px) เมื่ออยู่แถวเดียวกัน
- Input ที่มี prefix / suffix (`nz-input-group` / `nz-input-wrapper`) และช่อง Search ขนาดเริ่มต้นสูง 40px เท่ากัน; ขนาด large ยัง 48px
- Textarea ไม่เปลี่ยน (ยังเริ่ม 80 / 96px)

## เพิ่มใหม่
- token `--aibox-size-control-height` (40px, วัดจาก Figma ไม่ใช่ variable) คู่กับ `--aibox-size-control-height-lg` (48px)

## ผลกระทบ
- ทุกหน้าที่ใช้ `<input nz-input>` ขนาดเริ่มต้นจะสูงขึ้น 6px; ช่อง input ใน Pagination (quick jumper) ที่ override ยังไม่ครอบคลุมก็สูง 40px ด้วย

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1 และ 22.1.2 ได้ค่าเท่ากัน: Input / small / error / readonly / prefix / search / addon group = 40px, large / password = 48px, textarea 80 / 96px

## ยังเป็นคำถามถึง designer
- label เริ่มต้น 14/24 แต่ Figma small เป็น 12/22 (ใช้ class `aibox-form-small` ได้ถ้าต้องการ 12/22)
