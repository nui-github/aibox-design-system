# v0.56.2 – หมายเหตุ NZ_DATE_LOCALE ใน Getting started
วันที่: 2026-11-27

เอกสารเท่านั้น ไม่มีการเปลี่ยนหน้าตา

## เอกสาร
- Getting started และ README: ปฏิทินภาษาไทยต้องมี locale ของวันที่ด้วย ng-zorro 18–21 ใช้ `registerLocaleData(th)` ส่วน ng-zorro 22 ใช้ `{ provide: NZ_DATE_LOCALE, useValue: 'th-TH' }` (จาก `ng-zorro-antd/core/time`) ซึ่งต้องอยู่หลัง `provideNzNativeDateAdapter()` เพราะ adapter มีค่าเริ่มต้นของมันเอง ถ้าใส่ก่อน ค่าจะถูกทับและหัวปฏิทินเป็น "November 2026" (พบตอนวัดบนแอปทดสอบ 22.1.2 เว็บเอกสารเรียงถูกอยู่แล้ว)
- มีบล็อกโค้ดลำดับ providers ของ ng-zorro 22 ในหน้า Getting started
