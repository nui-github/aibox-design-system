# v0.23.0 – Upload
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ `nz-upload` ตาม Figma หน้า Upload: drop zone (`1516:11121`, `nzType="drag"`) พื้น `bg/secondary` เส้นประ 1px สี `text/secondary` มุม 8px สูง 148px, ไอคอน file-arrow-up 28px สี `bg/main` (วาดด้วย CSS แทน inbox ของ ng-zorro), ข้อความ 16/26 medium และคำอธิบาย 14/24 สี `text/secondary`
- แถวไฟล์ (upload-block `1516:11080`) สูง 64px padding 14 มุม 8px ขอบ 1px สี `border/secondary`: ชื่อไฟล์ 16/26 medium สี `text/main`, ไอคอนไฟล์ 16px และปุ่มลบในกล่อง 32px สีเทา
- สถานะ uploading: ขอบเส้นประ สปินเนอร์สีน้ำเงินหมุน (ซ่อนแถบ progress); error: ขอบ ไอคอน ชื่อ และปุ่มลบเป็นสีแดง `text/status/error-100`; `nzListType="picture"` แสดงรูป thumbnail 36px มุม 4px
- หน้า Upload ในเว็บเอกสาร (route `/upload`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| drop zone state=default | `<nz-upload nzType="drag">` + `.ant-upload-drag-icon` / `.ant-upload-text` / `.ant-upload-hint` |
| upload-block uploaded | `nzListType="text"` ไฟล์ status `done` |
| upload-block loading | status `uploading` |
| upload-block error | status `error` |
| upload-block thumbnail uploaded | `nzListType="picture"` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-upload` ทุกตัวเปลี่ยนหน้าตา: ไอคอนในรายการไฟล์ถูกแทนที่ด้วยไอคอนของ override และแถบ progress ของไฟล์ที่กำลังอัปโหลดถูกซ่อน
- สีขอบ drop zone ตอน hover (`color/main`) เป็นค่าที่ผมเพิ่มเอง Figma ไม่มีสถานะ hover ควรให้ designer ยืนยัน
- ไอคอนถังขยะ/ไอคอนอื่นใน ng-zorro ต้องลงทะเบียน (`DeleteOutline`, `InboxOutline`, `PaperClipOutline`, `FileOutline`, `PictureOutline`, `LoadingOutline`) ไม่งั้น console ฟ้อง `<svg> tag not found` และถ้าไม่ปิดปุ่ม preview/download ด้วย `nzShowUploadList` จะมีไอคอน eye/download เพิ่ม
- ไอคอนถังขยะเป็นแบบเส้น (Figma ใช้ glyph ทึบของ Font Awesome)

## ยังไม่ครอบคลุม
- สถานะ drop zone แบบ disabled, reduce-height, loading/completed/reupload/validation error (ทั้งแบบเต็มและ compact) และแบบมีปุ่มดาวน์โหลด
- ข้อความผิดพลาดใต้ชื่อไฟล์แบบ inline ใน upload-block (ng-zorro แสดงเป็น tooltip เท่านั้น)
- แถบ progress, `nzListType="picture-card"`
