## แก้ไข
- `--aibox-font-weight-semibold` เดิมเป็น `SemiBold` (CSS อ่านไม่ได้) เป็น **`600`**

## เพิ่มใหม่ (token ที่ Figma มีแต่ `tokens.css` ยังไม่มี)
- `--aibox-font-weight-regular` (400), `--aibox-font-weight-medium` (500)
- `--aibox-color-global-gray-90` (#f7f7f7), `--aibox-color-bg-subtle` (= gray-90), `--aibox-color-component-divider` (= gray-100, #f1f2f3)
- `--aibox-shadow-base-header-mobile` (0 4px 8px 2px #0000000a), `--aibox-shadow-base-bottom` (0 -3px 8px 0 #0000001a)
- `--aibox-blur-base-bg-transparency` (blur(5px)), `--aibox-blur-base-bg-solid` (blur(10px)), `--aibox-blur-sm` (blur(5px))

## component token ชี้ไปที่ token ของ Figma (แทนค่าตายตัว)
- `--aibox-dropdown-section-bg` = `var(--aibox-color-bg-subtle)` (ค่าเท่าเดิม #f7f7f7)
- `--aibox-card-menu-shadow` = `var(--aibox-shadow-base-header-mobile)` (ค่าเท่าเดิม)
- `--aibox-divider-band-color` = `var(--aibox-color-component-divider)` **สีเปลี่ยนจาก #f8f8f8 เป็น #f1f2f3** (แถบของ Divider ตามธีม S 10 / M 18 / M 24 เข้มขึ้นเล็กน้อย)

## ตรวจแล้ว
- ทุกค่าข้างต้นตรงกับตารางในเอกสารที่ได้รับ (ตรวจเทียบทีละตัวใน `dist/tokens.css`) และ `npm test` ผ่าน (849 token)
- วัดหน้าเว็บบน ng-zorro-antd 22.1.2: Divider, Dropdown, Card ต่างจากเดิมเฉพาะสีแถบของ Divider (248 → 241,242,243) ส่วน Dropdown กับ Card ค่าเท่าเดิม

## ยังไม่ได้ทำ (ตามเอกสาร)
- เส้น inline 1px ของ Divider ใน override ยังใช้ `border/primary` (Figma ใช้ `component/divider`) เป็นการแก้ component ไม่ใช่ token จะทำแยก
- ลบ token เก่าที่ไม่มีใน Figma แล้ว (`spacing-value-*`, `radius-value-6`, `size-*`, `switch-*`) เป็นการเปลี่ยนแบบ major แนะนำรวมรอบเดียวกับการขึ้นเลขเวอร์ชันใหญ่
