# v0.56.1 – บันทึกการตัดสินใจ: Steps แบบจุด, Tree แบบ checkbox, ความสูงตัวห่อ checkbox
วันที่: 2026-11-27

เอกสารเท่านั้น ไม่มีการเปลี่ยนหน้าตา

## เอกสาร
- Steps แบบจุด (`nzProgressDot`, F17): ตัดสินใจคงจุด 8px (10px ของขั้นปัจจุบัน) ที่ทำไว้ และบอกในหน้า Steps และ README ว่าแบบจุดไม่มีใน Figma (master ไม่มี layout ของแถวแบบจุด) เป็นการอนุมานของ override รอ designer
- Tree แบบ checkbox และ Tree select: ตัดสินใจคงสี hover (`bg/tertiary` ทั้งแถว) และ selected (`color/main` ตัวหนา) ที่ยืมจากเฟรม Folder-list และบอกในหน้า Tree และ README ว่า tree-selection-list ใน Figma ไม่มี state นี้ ยังไม่ได้รับการยืนยันจาก designer
- แก้ความเข้าใจใน release note ของ v0.56.0: ความสูงตัวห่อของ checkbox / radio ไม่ใช่ค่าตายตัว (24 / 22 / 28) แต่เป็นค่าที่มากกว่าระหว่างกรอบ (20 / 24 / 28) กับความสูงบรรทัดของ label ตัวเลขนั้นมาจากแอปทดสอบที่ label สูง 22px บนเว็บเอกสาร label สูง 24px จึงได้ 24 สำหรับ checkbox small สิ่งที่ตายตัวคือกรอบและการจัดกึ่งกลางระหว่างกรอบกับข้อความ ขอบคุณที่ site session จับได้

## ตรวจแล้วและไม่แก้
- Upload (ไอคอน): Figma upload-block (1516:11108) ใช้ไอคอนไฟล์ glyph 16px ในกล่อง 24px และไอคอนถังขยะ 16px ในกล่อง 32px ตรงกับ CSS ปัจจุบันอยู่แล้ว
