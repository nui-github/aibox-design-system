# v0.30.0 – Upload / Cascader states และตรวจบน ng-zorro 18.2.1
วันที่: 2026-11-13

## เพิ่มใหม่
- Upload: สถานะ `disabled` (ไอคอน `text/disable`, ชื่อ `text/tertiary`, hint `text/icon/default`, เคอร์เซอร์ not-allowed) และโหมดลดความสูง `aibox-upload-compact` (กล่อง 98px ไอคอนอยู่ข้างข้อความ)
- Cascader: แถวสองบรรทัดด้วย `nzOptionRender` + คลาส `aibox-option`, `aibox-option-icon`, `aibox-option-text`, `aibox-option-title`, `aibox-option-desc` (แถว 74px, แถวบรรทัดเดียวยัง 50px)
- Table: hover แถวตามของ ng-zorro (พื้น `#fafafa` ผ่าน token `--aibox-table-row-hover-bg`; ไม่มีใน Figma)
- เว็บเอกสาร: demo "Compact and disabled" ในหน้า Upload, demo "Two-line rows" ในหน้า Cascader, คลาสใหม่ในตารางหน้า Getting started

## แก้ไข
- Menu: `nz-submenu` ที่ปิดอยู่ไม่เว้น 24px ท้ายกลุ่มอีก (เว้นเฉพาะตอนเปิด) — พบบน ng-zorro-antd 18.2.1 ที่คง submenu ที่ปิดไว้ใน DOM ที่ความสูง 0; วัดแล้วบน 22.1.2 และ 18.2.1 ได้ผลเดียวกัน (250/57px)

## ตรวจบน ng-zorro-antd 18.2.1
- วัดใน DOM จริงเทียบกับ 22.1.2: Message, Modal, Empty, Scrollbar, Drawer, Table, Tree, Card, Upload และแถว Cascader สองบรรทัดได้ค่าเท่ากัน; Date picker / Time picker / Cascader ต่างกัน 1–8px เพราะ DOM ของสองเวอร์ชันต่างกัน
- ความต่างของ API ใน 18 ดู README หัวข้อ "Verified on ng-zorro-antd 18.2.1"

## ยังเป็นค่าที่อนุมาน (ต้องให้ designer ยืนยัน)
- hover/selected ของ Date picker, Tree, Cascader; hover แถวกลุ่มของ Menu และแถวของ Dropdown; เส้นคั่นแถวและสี hover ของ Table (ใช้ค่า ng-zorro); border ตอน hover ของ Upload; Card Menu ไม่มี hover
- ไม่ได้ตรวจใน Ai-BOX จริง และลิงก์ jsDelivr ต้องให้ผู้ใช้ตรวจ
