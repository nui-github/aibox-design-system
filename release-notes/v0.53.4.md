# v0.53.4 – Menu: รายการเดี่ยวมี hover / selected เหมือนรายการในกลุ่ม
วันที่: 2026-11-25

## แก้ไข
- Menu แนวตั้ง: `nz-menu-item` ระดับบนสุด (รายการเดี่ยว ไม่อยู่ในกลุ่ม) ยังใช้สี hover / selected ของ ng-zorro เดิม (พื้นฟ้าอ่อนของ Ant ไม่มีตัวอักษรหนา) ตอนนี้เหมือนรายการย่อยในกลุ่ม: hover = พื้น `component/bg/bg-active` ตัวอักษร `color/main` medium, `nzSelected` = พื้น `bg/main` ตัวอักษรขาว medium
- แถวยังสูง 56px และพื้นเต็มความกว้างของแถว (Figma ไม่มีสเปกของรายการเดี่ยว รายการย่อยในกลุ่มเป็นแถบมน 208×32 ที่เว้นขอบ 16px แต่แถวเดี่ยวต้องคงตัวอักษรที่ x=16 จึงไม่ทำเป็นแถบมน)
- เว็บเอกสาร: demo "แถวบนสุด (รายการเดี่ยว)" ในหน้า Menu มีแถว `nzSelected` เพิ่ม และคำอธิบายพูดถึง hover / selected
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): สีพื้น สีตัวอักษร และน้ำหนักตัวอักษรของ hover / selected เท่ากับรายการย่อยในกลุ่มทุกเวอร์ชัน

## หมายเหตุ
- ถ้านักออกแบบอยากให้รายการเดี่ยวเป็นแถบมนแบบรายการย่อย (มีสเปกใหม่ใน Figma) ให้แจ้ง จะปรับรูปทรงได้
