# v0.52.0 – Spin (nz-spin) ตาม Figma หน้า Spin
วันที่: 2026-11-25

## เพิ่มใหม่
- override ของ `nz-spin` ตาม Figma หน้า Spin (`7075:39`, Spin `7075:49`): `<nz-spin nzSimple nzTip="Loading">` ตัวหมุน 14 / 20 / 32px (`nzSize` small / default / large) ข้อความใต้ตัวหมุน 14/22 padding 16 ช่องว่าง 8 กึ่งกลาง กล่องสูง 76 / 82 / 94px ตรง Figma
- `nz-spin` ที่ครอบเนื้อหา ใช้ overlay ของ ng-zorro เปลี่ยนเฉพาะสีตัวหมุนและข้อความเป็นสีหลัก `--aibox-color-main`
- เว็บเอกสาร: หน้า Spin ใหม่ (Size, ครอบเนื้อหา) พร้อมเมนู
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): ขนาดกล่อง ตัวหมุน ข้อความ และสี เท่ากันทุกเวอร์ชัน

## หมายเหตุ
- หน้า Spin ใน Figma เป็น Ant Design ดั้งเดิม ไม่ได้ใช้ token ของ aibox (สี `Components/Spin/Global/colorPrimary` = `#1677ff`, ฟอนต์ SF Pro Text) override จึงเก็บ "ขนาดและระยะ" ตาม Figma แต่ใช้สีหลักและฟอนต์ของ Ai-BOX แทน ถ้านักออกแบบต้องการสีฟ้าของ Ant เดิม ให้แจ้ง (เปลี่ยนที่เดียว)
- ข้อความ tip ใช้ line-height 22px ตาม Figma (token ตัวอักษร body เป็น 24px) เพื่อให้กล่องสูงเท่าเดิม
- ยังไม่ครอบคลุม: ตัวหมุนกำหนดเอง (`nzIndicator`), dark theme
