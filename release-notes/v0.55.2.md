# v0.55.2 – คอลัมน์ checkbox ของ Table สูง 48 ตาม Figma และผลวัดเพิ่ม
วันที่: 2026-11-27

## แก้ไข
- คอลัมน์ checkbox ของ Table (T32): พบจากการวัดว่าหัวตารางที่มี `nzShowCheckbox` สูง 52.8px (Figma 48px) เพราะ `nz-table-selection` เป็น inline-flex และเส้นฐานของมันดันบรรทัดสูงขึ้น ตอนนี้ตัวห่อเป็น flex, checkbox อยู่ในกรอบ 20 × 24 ตรงกลาง และ padding เป็น 12/16 (หัว) และ 8/16 (แถว) ตาม Figma head cell 10893:1099 วัดได้หัว 52 × 48 แถว 52 × 58 เท่ากันบน 18.2.1, 19.3.1, 20.4.4, 21.3.3, 22.1.2 (v0.53.7 บอกว่าคอลัมน์กว้าง 52px แต่ยังไม่ได้วัดความสูงของหัว)

## เอกสาร
- หน้า Table: demo ใหม่ "Checkbox column" (เลือกทีละแถว, เลือกทั้งหมด, สถานะ indeterminate) วัดบน 22.1.2 ได้หัว 52 × 48 แถว 52 × 58

## ตรวจแล้วและไม่แก้ (ผลวัดเพิ่ม บน 18.2.1, 19.3.1, 20.4.4, 21.3.3, 22.1.2)
- ไอคอน Tag checkable: กล่อง 16 × 16, glyph 12px, สีขาวตอนเลือก, `text/icon-default` (#bbbec4) ตอนเลือก + disabled; ความสูง tag 32 / 24 / 42 เท่ากันทุกเวอร์ชัน
- Tooltip ทั้ง 12 ตำแหน่ง: ขนาดกล่อง ขนาดลูกศร 16 × 16 และระยะลูกศรจากขอบเท่ากันทุกเวอร์ชัน (เทียบ 18/19/20/21 กับ 22)
- Select ที่ disabled: Figma (1:7223) ค่าและ placeholder เป็น `text/secondary` ลูกศร #bbbec4 ซึ่งตรงกับ CSS เดิมอยู่แล้ว ไม่ต้องแก้ (label ของมันตามกฎ `:has()` ใน v0.55.1)
- รอบก่อนหน้านี้: เมนูคำสั่ง 216px, แถว Select ที่มีคำอธิบาย 74/62px, แถบท้ายปฏิทิน, ลูกศร Tree 16px และสี disabled วัดซ้ำแล้วเท่ากันทุกเวอร์ชัน
