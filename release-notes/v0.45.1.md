# v0.45.1 – Upload compact: ไอคอนติดหัวข้อและอยู่กึ่งกลางตาม Figma
วันที่: 2026-11-23

## แก้ไข
- Upload แบบ compact (`aibox-upload-compact`, Figma state reduce-height node `5497:9444`): ไอคอนกับหัวข้อ ("คลิกหรือลากไฟล์มาที่นี่") อยู่ติดกันและแถวนี้อยู่กึ่งกลางกล่อง เดิมไอคอนอยู่ห่างจากหัวข้อมาก (วัดได้ 134.6px ในเครื่องทดสอบที่ไม่มีฟอนต์ IBM Plex Sans Thai จริง ค่าก่อนแก้ขึ้นกับความกว้างของคำอธิบาย จึงต่างกันตามฟอนต์) เพราะคำอธิบายใต้แถวถูกให้คร่อมสองคอลัมน์ของกริด `auto auto` ความกว้างส่วนเกินของคำอธิบายจึงถูกแจกให้คอลัมน์ของไอคอนและของหัวข้อ ไอคอนไปอยู่ชิดซ้ายของคอลัมน์และหัวข้อถูกจัดกลางในคอลัมน์ที่ขยาย
- ตอนนี้กริดเป็น `1fr auto auto 1fr` ส่วนเกินไปอยู่ที่สองข้าง คู่ไอคอนกับหัวข้อจึงกว้างเท่าเนื้อหาและอยู่กึ่งกลางเสมอ ระหว่างกล่องไอคอน (32px) กับตัวหนังสือ gap 0 ตาม Figma (ตัวสัญลักษณ์ 20px ในกล่อง 32px จึงห่างตัวหนังสือ 6px) ค่า `column-gap` เดิม 8px ถูกเอาออก
- ผลต่อผู้ใช้: ไอคอนเลื่อนเข้าหาหัวข้อและทั้งแถวอยู่กึ่งกลาง ระยะบน / ล่างของกลุ่มยัง 22px เท่ากัน (ตรงกับ Figma: 98px, padding 20, เนื้อหา 56px) ความสูงกล่อง 100px เท่าเดิม

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 22.1.2 (เว็บเอกสาร) และ 18.2.1 / 19.3.1 / 20.4.4 / 21.3.3 (แอปเล็ก): กล่อง 480 x 100, กล่องไอคอน 32 x 32, ช่องว่างระหว่างกล่องไอคอนกับตัวหนังสือ 0px, ศูนย์กลางของแถวไอคอน+หัวข้อและของคำอธิบายตรงกับศูนย์กลางกล่อง (ต่าง 0px), ระยะบน / ล่าง 22px ทั้งสองข้าง ค่าเท่ากันทุกเวอร์ชัน
- กล่องแคบ 360px และ 280px (คำอธิบายขึ้นสองบรรทัด): ช่องว่างยัง 0px แถวยังอยู่กึ่งกลาง คำอธิบายอยู่ในกล่อง
- `npm test` ผ่าน (846 token)
