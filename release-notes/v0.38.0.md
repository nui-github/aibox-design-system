# v0.38.0 – Tag แบบ naming (avatar + ชื่อ)
วันที่: 2026-11-18

## เพิ่มใหม่
- Tag ชื่อคนตาม Figma tag/closable style=naming round: class `aibox-tag-naming` บน `nz-tag` (ใช้กับ `nzMode="closeable"` ได้) แล้วใส่ avatar ไว้หน้าสุด `<span class="aibox-tag-avatar"><span nz-icon nzType="user"></span></span>` (หรือตัวอักษรแรกของชื่อ)
- หน้าตา: แท็กทรงแคปซูลสูง 30px พื้น `bg/secondary` มี avatar กลม 30px (พื้น `global/blue/200` ไอคอนคน `global/blue/700` 12px) ชิดขอบซ้าย ห่าง 8px จากชื่อ (14/24 medium สี `text/primary`) แล้วปุ่ม × 12px สี `text/primary` เว้นขอบขวา 12px
- `aibox-tag-naming-sm` = เฟรม naming round small: avatar 24px, เว้นขอบขวา 8px
- `aibox-tag-name` ครอบชื่อยาวให้ตัดด้วย … ที่ 120px (เฟรม "hug" ของ Figma ไม่จำกัดความกว้าง จึงไม่ต้องใส่ class นี้)
- เว็บเอกสาร: demo "Naming (avatar)" ในหน้า Tag (ไอคอน, small, ตัวอักษร + ชื่อยาว, แบบไม่มี ×), ไอคอน `user`, แถวคลาสในหน้า Getting started

## ยังไม่ครอบคลุม
- สีอื่นของ naming (Figma มีสีปกติสีเดียว), สถานะ hover ของ × (ไม่มีใน Figma), avatar แบบรูปถ่าย (ใส่ `<img>` ใน `aibox-tag-avatar` เอง)
