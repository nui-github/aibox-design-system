# v0.53.5 – จูนให้ตรง Figma ตามรายงานเปรียบเทียบ (ชุดที่ 1): error, ดาว required, Tab, Steps, Menu, Time picker
วันที่: 2026-11-26

ที่มา: รายงานเปรียบเทียบเว็บเอกสารของฝั่ง aibox-ui กับ `aibox-css` v0.53.4 (ข้อ T1, T4, T16, T42, T44, T48, T49, T50) ทุกข้อวัดซ้ำและอ่าน Figma ก่อนแก้

## แก้ไข
- **Input ตอน error (T1):** กฎของ ng-zorro (`.ant-input-status-error:not(.ant-input-disabled):not(.ant-input-borderless).ant-input`) specificity สูงกว่าของ aibox จึงยังได้ขอบแดง Ant `#ff4d4f` (focus `#ff7875` กับวง `rgba(255,77,79,.2)`): ตอนนี้ขอบ `state/form/error` (`#f25c5a`) 1px ทั้งปกติ / hover / focus และวง `state/form/error-outer` 2px (วัดบน 18.2.1–22.1.2) · Select multiple ตอน error วงในและวงนอกใช้ token ถูกอยู่แล้ว (ขอบสีแดง Ant ที่เห็นในค่า computed เป็นขอบกว้าง 0px ไม่มีผลต่อหน้าตา)
- **ดาว required (T4):** ตาม Figma Label (`7124:95946`) ดาวอยู่ "หลัง" ข้อความ label ห่าง 4px สี `text/status/error-100` ขนาดเดียวกับ label (14/24 หรือ 12/22): เดิมเป็นดาวแดงของ Ant หน้า label (`#ff4d4f`) ดาวใหม่แทนที่เครื่องหมาย `:` ของ label ที่ required (Figma ไม่มี colon)
- **Tab (T44, T16):** Tab แบบ card ห่างกัน 4px (Figma `4034:234` row gap 4, เดิมติดกัน 0) แบบเส้นยังติดกัน · Outline Tab สูง 48 / 40 / 32px (Figma `5342:5164`; เดิม 56 / 40 / 40 จากการอ่านผิดในครั้งก่อน) card ไม่เปลี่ยน
- **Steps (T48, T49):** แนวตั้ง: ข้อความอยู่กลางไอคอน หัวข้อ y=30 คำอธิบาย y=58 ห่าง 2px ตาม Figma (เดิม 25 / 51 ติดกันและสูงกว่ากลาง 6px เพราะ padding ล่าง 12px ของ ng-zorro) · เส้นก่อนขั้น error ครึ่งแรก `bg/main` ครึ่งหลัง `bg/secondary` (Figma active=step2 error: ตรวจจากพิกเซลที่ 25% / 75% ของเส้น ทั้งแนวนอนและแนวตั้ง; แก้ข้อสงสัยที่ค้างใน v0.51.0)
- **Menu (T50):** กลุ่มที่ปิดสูง 56px (เดิม 57: เส้นล่าง 1px อยู่นอกหัวข้อ) เมนูตัวอย่างบนหน้า demo สูง 248px ตาม Figma (v0.53.2 วัดจากแอปที่มีแต่กลุ่มที่เปิดจึงไม่เห็น)
- **Time picker (T42):** บนจอสัมผัส (`@media (hover: none)`) คอลัมน์เวลาเลื่อนได้ด้วยการปัด (ng-zorro เปิดการเลื่อนเฉพาะตอน `:hover` ซึ่งจอสัมผัสไม่มี) คอลัมน์เลื่อน ~118px หน้าไม่เลื่อน วัดบนทั้ง 5 เวอร์ชัน · เมาส์ไม่เปลี่ยน (ยังเป็น hidden จนกว่าจะ hover)
- เว็บเอกสาร: คำอธิบาย demo Error ของ Steps พูดถึงเส้นครึ่งสี

## ตรวจแล้ว
แอปทดสอบเล็กบน ng-zorro-antd 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2: Input error (ปกติ / focus), ดาว required (หลัง label 4px, `#f04542`), Tab (card 4px × 48 / 40 / 32, เส้น 0px × 48 / 40 / 32), Steps แนวตั้ง (30 / 58, แนวนอน 32 / 60 ไม่เปลี่ยน), เมนู (56 / 56 / 56 / 192), Time picker บนจอสัมผัสจำลอง เท่ากันทุกเวอร์ชัน
