# v0.13.0 – Breadcrumb
วันที่: 2026-11-09

## เพิ่มใหม่
- override ของ `nz-breadcrumb` ตาม Figma หน้า Breadcrumb (breadcrumbs `1:11308`, breadcrumbs_lists `7762:53685`): ข้อความ 12/22 สีเทา `gray/g-5` (hover และตอนกดเป็นเทาเข้มขึ้น), รายการสุดท้ายตัวหนา (500) สี `text/primary` ไม่มีตัวคั่น, ตัวคั่นเป็นลูกศร chevron 12px (วาดด้วย CSS แทน "/" ของ ng-zorro) ระยะห่าง 4px
- รองรับ 2 ถึง 5 ระดับ (`nz-breadcrumb-item` ตามจำนวนระดับ)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| breadcrumbs state=default | `nz-breadcrumb-item` ที่ไม่ใช่รายการสุดท้าย |
| state=hover / pressed | ลิงก์ (`<a>`) ที่ hover / กด |
| state=active | `nz-breadcrumb-item` สุดท้าย |
| breadcrumbs_lists level=2..5 | `nz-breadcrumb` ที่มี 2 ถึง 5 รายการ |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-breadcrumb` ทุกตัวเปลี่ยนหน้าตา: ตัวอักษร 12px (เดิม 14px), ตัวคั่นเป็นลูกศร chevron แทน "/" และระยะห่างเปลี่ยน
- ถ้ากำหนด `nzSeparator` เอง (ข้อความหรือ template) จะถูกซ่อน ให้ใช้ค่าเริ่มต้น
- Figma ไม่มีสีแยกของสถานะ pressed (ใช้สีเดียวกับ hover)

## ยังไม่ครอบคลุม
- รายการแบบ dropdown (`nzOverlay`)
