# v0.47.7 – Select multiple: placeholder เริ่มที่เดียวกับ Select ธรรมดาบน ng-zorro 20+
วันที่: 2026-11-24

## แก้ไข
- Select แบบ `nzMode="multiple"` / `"tags"` ที่ยังไม่มีค่า: ng-zorro-antd 20+ ห่อแท็กและ placeholder ไว้ใน `span.ant-select-selection-wrap` (position: relative) ซึ่งเริ่มหลัง padding ของกล่องอยู่แล้ว placeholder จึงเริ่มที่ 16px (large 24px) ขณะที่ 18 / 19 เริ่มที่ 8px (large 12px) ตาม Figma select (`1:7137`) และ tag-selection (`3959:10071`) ตั้ง `left: 0` ให้ placeholder ที่อยู่ใน `.ant-select-selection-wrap`
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): placeholder ของ multiple เริ่มที่ 8px / 12px เท่ากันทุกเวอร์ชัน (เดิม 20 / 21 / 22 เริ่มที่ 16px / 24px)

## ตรวจแล้วว่าตรงกับ Figma อยู่แล้ว (ไม่ได้แก้)
- Cascader (field): เป็น select เดียวกัน ข้อความเริ่มที่ 8px / 12px ลูกศรห่างขอบขวา 10px / 14px กึ่งกลางแนวตั้ง เท่ากันทุกเวอร์ชัน (Cascader Containment `4268:13151`)
- Cascader (เมนู): แถวสูง 50px ข้อความเริ่มที่ 16px ลูกศรขยายห่างขอบขวา 16px ตรง content-list `1:7627` บน 19.3.1 และ 22.1.2
- Select multiple ที่มีแท็ก: แท็กแรกเริ่มที่ 8px / 12px จากซ้ายและ 8px / 12px จากบน สูง 24px แถวห่าง 8px ลูกศรห่างขอบขวา 10px / 14px ตรง tag-selection ทุกเวอร์ชัน

## หมายเหตุ
- Figma วางลูกศรของ Select multiple (กล่องหลายแถว) สูงกว่ากึ่งกลางแถวแรก 3px (cta y=11 ใน large, y=7 ใน small) ขณะที่ Select เดี่ยวอยู่กึ่งกลาง ลูกศรใน override อยู่กึ่งกลางแถวแรก ควรให้นักออกแบบยืนยัน
