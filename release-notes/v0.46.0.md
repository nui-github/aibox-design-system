# v0.46.0 – Upload: แถวไฟล์ใต้ drop zone (กำลังอัปโหลด / ผิดพลาด / สำเร็จ)
วันที่: 2026-11-23

## เพิ่มใหม่
- `aibox-upload-inline` (บน `nz-upload nzType="drag"` + `[nzFileList]`): แถวไฟล์ใต้ drop zone ตาม Figma Upload state loading / error / completed (node `1516:11130` / `1516:11133` / `1516:11138`) เป็นแถวเปล่าไม่มีกรอบ ห่างโซน 10px สูง 32px: กล่องไอคอน 24px (ไอคอน 16px: วงกลมหมุนตอนอัปโหลด, ไอคอนไฟล์), ช่องไฟ 8px, ชื่อไฟล์ 16/26 medium สี `color/main` (สีแดง `text/status/error/100` ตอน error) และปุ่มลบ 32px (เทา, แดงตอน error) สถานะมาจาก `status` ของไฟล์: `uploading` / `error` / `done` ถ้าไม่ใส่ class แถวยังเป็นกล่อง upload-block 64px แบบเดิม (ไม่เปลี่ยนค่าเริ่มต้น)
- `aibox-upload-error-text`: บรรทัดข้อความผิดพลาดของไฟล์ (ไอคอนวงกลมอัศเจรีย์ในกล่อง 24px + ช่องไฟ 8px + ข้อความ 14/24 สีแดง) ผู้ใช้วางเองใต้ `nz-upload` เพราะ ng-zorro ทุกเวอร์ชันแสดง `file.message` เป็น tooltip เท่านั้น ข้อความเริ่มที่ 32px ตรงกับชื่อไฟล์เหมือน Figma ไอคอนวาดด้วย CSS (ไม่ต้องลงทะเบียนไอคอน)
- เว็บเอกสาร: demo "File status under the zone" (หน้า Upload) และแถวคลาสใหม่ 2 แถวในหน้า Getting started

## ข้อควรรู้
- ng-zorro / Ant ตั้งโซนลากไฟล์เป็น `height: 100%` ถ้าโซนอยู่ในคอนเทนเนอร์แบบกริด / flex ที่ความสูงถูกยืด ความสูงนั้นจะนับรวมรายการไฟล์ โซนจะขยายเป็น 190px (แถวไฟล์ล้นไปโดนบล็อกถัดไปทับ) `aibox-upload-inline` จึงตั้งโซนเป็น `height: auto` (ทดสอบในสภาพที่ยืดช่องแล้ว: โซนยัง 148px ทุกเวอร์ชัน) โซนแบบไม่ใช้ class นี้ยังเป็นค่าเดิมของ ng-zorro
- ng-zorro เปิดปุ่ม preview ให้ไฟล์ที่ `done` เป็นค่าเริ่มต้น ให้ใส่ `[nzShowUploadList]="{ showPreviewIcon: false, showRemoveIcon: true, showDownloadIcon: false }"` เพื่อให้เหลือปุ่มลบปุ่มเดียวตาม Figma
- Figma วาดไอคอนของ loading / completed ขนาด 20px แต่ error ขนาด 16px (แถวสูง 29px แต่เนื้อหา 32px ล้นออก) ใช้ 16px ทุกสถานะและแถวสูง 32px ตามสถานะ error ความสูงรวม: error 214px ตรงกับ Figma, loading / completed 190px (Figma 187px)

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปเล็ก) ได้ค่าเท่ากันทั้ง 5 เวอร์ชันทั้ง 3 สถานะ (รวมกรณีที่โซนอยู่ในคอนเทนเนอร์ที่ยืดช่อง): โซน 148px, ห่างแถว 10px, แถว 480 x 32 ไม่มีกรอบ, กล่องไอคอน 24px, ชื่อเริ่มที่ 32px ขนาด 16/26 น้ำหนัก 500 สี `rgb(31, 93, 249)` (error `rgb(240, 69, 66)`), ปุ่มลบ 32px ชิดขอบขวา, ข้อความผิดพลาดสูง 24px เริ่มที่ 32px
- `npm test` ผ่าน (846 token)
