# v0.25.0 – Time picker
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ `nz-time-picker` ตาม Figma หน้า TimePicker (time-picker-desktop `1612:3566`, menu cell `1613:9223`)
- ช่อง: ใช้สไตล์เดียวกับ Date picker (small / large, error, disabled, โฟกัส) ไอคอนนาฬิกาสี `text/icon-default`
- แผงเลือกเวลา: กว้างราว 125px พื้น `bg/primary` มุม 6px เงา raise-modal padding บน 10px, คอลัมน์สูง 224px คั่นด้วยเส้น 1px สี `border/primary`
- ช่องตัวเลข 28×28 มุม 4px ตัวอักษร 14/24: hover พื้น `bg/tertiary`, ที่เลือกพื้น `color/main` ตัวอักษรขาว medium
- ปุ่มยืนยัน (`nzNeedConfirm`) แสดงเป็นปุ่ม outlined ขนาดเล็กเต็มความกว้าง padding 12 และซ่อนลิงก์ "now" ที่ไม่มีใน Figma
- token ใหม่ `--aibox-timepicker-menu-radius` (6px) ใน `tokens/component.json`
- หน้า Time picker ในเว็บเอกสาร (route `/time-picker`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| size Large / small | `nzSize="large"` / ค่าเริ่มต้น |
| state error / disabled | `nzStatus="error"` / `nzDisabled` |
| expand / edit | แผงที่เปิดจากช่อง (`nzFormat="HH:mm"` ให้เหลือชั่วโมงกับนาที) |
| ปุ่ม "เลือก" ท้ายแผง | `[nzNeedConfirm]="true"` |

## ที่ต้องรู้ก่อนอัปเกรด
- ng-zorro 22 ต้องมี date adapter ใน providers (`provideNzNativeDateAdapter()`) เช่นเดียวกับ Date picker
- `nz-time-picker` ทุกตัวเปลี่ยนหน้าตา และลิงก์ "now" ถูกซ่อน
- ข้อความบนปุ่มยืนยันมาจาก locale ของแอป (ภาษาไทยของ ng-zorro เป็น "ตกลง" ส่วน Figma เขียน "เลือก")

## ยังไม่ครอบคลุม
- คอลัมน์วินาที / 12 ชั่วโมง (`nzUse12Hours`), เฟรมมือถือ (time-picker-mobile `1630:2916`)
- แผงของ `nz-time-picker` ที่มีหลายคอลัมน์เลื่อนในกล่องเดียวที่ยาวกว่า 8 แถว ตรวจเฉพาะ 2 คอลัมน์ (HH:mm)
