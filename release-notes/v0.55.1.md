# v0.55.1 – สีตอน disabled ตาม Figma และหมายเหตุชื่อมุม Tooltip
วันที่: 2026-11-26

## แก้ไข
- สีตอน disabled (T3): ตรวจกับ Figma textfield disabled (1:7121 และ 1:7129) แล้ว ค่าของช่องเป็น `text/secondary` (เดิม `text/disable`), placeholder เป็น `text/disable`, label และ assistive text เป็น `text/disable` (เดิม label เป็น `text/secondary`) ตอนนี้ Input, Input number, ช่องมี prefix/suffix และ Date/Range picker ตามนี้ ส่วน label และข้อความช่วยของ `nz-form-item` ที่มีช่อง disabled (Input, Input number, Select, picker) เป็น `text/disable` อัตโนมัติด้วย `:has()` ไม่ต้องใส่ class
- วัดบน 22.1.2: label และข้อความช่วย #adb0b8, ค่า #6b707b, placeholder #adb0b8; form item ปกติยัง #6b707b เหมือนเดิม

## เอกสาร
- Tooltip (T35): ตรวจ Figma `top left` (1145:1173) แล้ว ลูกศรอยู่ห่างขอบขวา 16px จึงตรงกับ `nzTooltipPlacement="topRight"` ของ Ant (ชื่อมุมกลับกัน) ใส่ในหน้า Tooltip และ README

## ข้อควรรู้
- ผลต่อแอปที่ใช้อยู่: ข้อความในช่อง disabled จะเข้มขึ้น (จาก #adb0b8 เป็น #6b707b) และ label ของช่อง disabled จะจางลง (จาก #6b707b เป็น #adb0b8) ตามที่ Figma กำหนด
- form item ที่มีหลายช่อง ถ้ามีช่องใดช่องหนึ่ง disabled label ทั้งอันจะเป็นสีจาง
- ค่าของ Select ที่ disabled ยังไม่ได้เปลี่ยน (ยังไม่ได้ตรวจกับ Figma)
- วัดบน 22.1.2 เท่านั้น
