# v0.15.0 – Alert
วันที่: 2026-11-09

## เพิ่มใหม่
- override ของ `nz-alert` ตาม Figma หน้า Message & Snack Bar (alert-bar `1:10675`): พื้นตามสถานะ `bg/status/*-100` (success / info / warning / error), ข้อความ 16/26 `text/primary`, padding 8×12, มุม 4px, ไม่มีขอบ
- ไอคอนสถานะ 20px แบบวงกลมเส้น (วาดด้วย CSS แทนไอคอนทึบของ ng-zorro) สีตามสถานะ และไอคอนปิด 12px สีเทา (`nzCloseable`)
- `aibox-alert-shadow` ยกลอยด้วยเงา raise-modal (ใช้เมื่อลอยทับเนื้อหา) และ `aibox-alert-inset` เว้นขอบซ้ายขวา 16px (Figma type=padding) ใช้ร่วมกันได้

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| status success / info / warning / error | `nzType` |
| ไอคอน | `nzShowIcon` |
| Close button yes / no | `nzCloseable` / ไม่ใส่ |
| shadow yes / no | `aibox-alert-shadow` / ไม่ใส่ |
| type full-width / padding | ค่าเริ่มต้น / `aibox-alert-inset` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-alert` ทุกตัวเปลี่ยนหน้าตา: ไม่มีขอบ พื้นสีอ่อนแบบใหม่ ข้อความ 16px และไอคอนเป็นวงกลมเส้น
- ไอคอนที่ ng-zorro วาดจะถูกซ่อนและแทนด้วยไอคอนของ override (4 สถานะ) ถ้าใส่ไอคอนเอง (`nzIconType`) จะไม่แสดง
- `aibox-alert-*` ใส่ที่ `<nz-alert>` ได้ (ng-zorro วาด `.ant-alert` ไว้ข้างใน)
- สีไอคอนสถานะอ่านจากภาพ Figma (ไอคอนเป็นรูป SVG ไม่ใช่ตัวอักษร) ใช้ token `text/status/*-200` ควรให้ designer ยืนยัน

## ยังไม่ครอบคลุม
- `nzDescription` (แบบมีคำอธิบาย), banner mode, ส่วน snackbar และ message-bar ของหน้าเดียวกัน (`nz-message`)
