# v0.14.0 – Divider
วันที่: 2026-11-09

## เพิ่มใหม่
- override ของ `nz-divider` ตาม Figma หน้า Divider (divider `1174:444`): ค่าเริ่มต้นเป็นเส้น 1px สี `border/primary` (theme inline), `nzDashed` เป็นเส้นประ 1px สี `text/white-secondary` (Dash Secondary)
- แถบหนา: `aibox-divider-s` (5px, margin 10), `aibox-divider-m` (5px, margin 18), `aibox-divider-m24` (5px, margin 24) และ `aibox-divider-l` (แถบ 10px สี `bg/disable`, margin 18)
- token ใหม่ `--aibox-divider-band-color` (`#f8f8f8` สีแถบ ใน Figma เป็นค่า hex ตรงๆ ไม่ใช่ variable)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| theme = inline | `<nz-divider>` (ค่าเริ่มต้น) |
| theme = Dash Secondary | `nzDashed` |
| theme = S 10 / M 18 / M 24 | `aibox-divider-s` / `aibox-divider-m` / `aibox-divider-m24` |
| theme = L space18 | `aibox-divider-l` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-divider` ทุกตัวเปลี่ยนสีเส้น (เทาอ่อน `#f1f2f3` แทน `rgba(0,0,0,.06)`) เส้นประเป็น `#e4e5e7` margin ของ ng-zorro (24px) ไม่เปลี่ยน (Figma ไม่กำหนด margin ให้เส้น inline)
- divider แนวตั้งและแบบมีข้อความเปลี่ยนแค่สีเส้น (Figma ไม่มีดีไซน์ของสองแบบนี้) แถบหนาใช้ได้เฉพาะแนวนอน

## ยังไม่ครอบคลุม
- แถบหนาแนวตั้ง, divider แบบมีข้อความ (ใช้สไตล์ของ ng-zorro เปลี่ยนแค่สี)
