# v0.50.0 – Collapse (nz-collapse) ตาม Figma หน้า Collapse
วันที่: 2026-11-25

## เพิ่มใหม่
- override ของ `nz-collapse` ตาม Figma หน้า Collapse (`1105:1930`, ตัวอย่าง `_Collapse / Collapse Item`): แบบ Basic (กรอบ 1px มุม 8px), Borderless (`[nzBordered]="false"` ไม่มีกรอบ คั่นแถวด้วยเส้น 1px) และ Ghost (`nzGhost` ไม่มีกรอบและพื้น หัวข้อ padding ซ้าย 12px)
- หัวข้อ padding 12×16 ช่องว่าง 12px ตัวอักษร 14/24 (large 16/26 padding 16 ซ้าย 24 ขวา, small 8 ซ้าย 12 ขวา) ลูกศร 12px ในกล่อง 16px: แถวที่เปิดใช้สีหลัก `--aibox-color-main` แถวที่ปิดใช้ `text/tertiary` เนื้อหา padding 16 ตัวอักษร 14/24
- `nzExpandIconPosition="end"` วางลูกศรทางขวา แถว disabled พื้น `bg/disable` ตัวอักษร `text/disable`
- class `aibox-collapse-small` / `aibox-collapse-large` สำหรับ ng-zorro 18 / 19 ซึ่งไม่มี `nzSize` (บน 20+ ใช้ `nzSize` ได้เลย)
- เว็บเอกสาร: หน้า Collapse ใหม่ (Basic, Borderless, Ghost, Size, Icon ขวา / Disabled) พร้อมเมนูและแถวคลาสใหม่ในตาราง Getting started
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): ขนาดหัวข้อ (small 40px, default 48px, large 58px), ตำแหน่งลูกศร / ข้อความ, สีเปิด / ปิด / disabled เท่ากันทุกเวอร์ชัน

## หมายเหตุ
- ชื่อ class ของ ng-zorro ต่างกันตามเวอร์ชัน (18–20: `content` / `content-box` / `header-text` / `icon-position`, 21+: `panel` / `body` / `title` / `icon-placement`) override ครอบทั้งสองชุด
- `nzDisabled` ของ panel ถูกเอาออกใน ng-zorro 22 ให้ใช้ `nzCollapsible="disabled"` (20+ ใช้ได้เช่นกัน) บน 18 / 19 ใช้ `[nzDisabled]`
- ยังไม่ครอบคลุม: Sub Navigation (`1108:6694`), รายการใน Collapse Content List นอกจากข้อความล้วน และ dark theme
