# v0.12.0 – Tooltip
วันที่: 2026-11-09

## เพิ่มใหม่
- override ของ `nz-tooltip` ตาม Figma หน้า Tooltip (tooltip `1145:1157`, tooltip-themed `1145:1219`): พื้นเข้ม `#404040` ตัวอักษรขาว 14/24 padding 6×8 มุม 4px ลูกศรห่างมุม 16px
- ธีมผ่าน `nzTooltipOverlayClassName`: `aibox-tooltip-light` (พื้นขาว มุม 8px เงา popover) และ `aibox-tooltip-blue` (พื้นฟ้าอ่อน มุม 8px)
- ขนาด: `aibox-tooltip-sm` (padding 6×14) และ `aibox-tooltip-xs` (ตัวอักษร 12/22, padding 4×8) ใช้ร่วมกับธีมได้ เช่น `"aibox-tooltip-blue aibox-tooltip-xs"`

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| tooltip (ทุก placement) | `nz-tooltip` + `nzTooltipPlacement` (ลูกศรอยู่ห่างมุม 16px อยู่แล้ว) |
| tooltip-themed light / blue | `nzTooltipOverlayClassName="aibox-tooltip-light"` / `"aibox-tooltip-blue"` |
| size small / xsmall | `aibox-tooltip-sm` / `aibox-tooltip-xs` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-tooltip` ทุกตัวเปลี่ยนหน้าตา: พื้นเข้มทึบ `#404040` (เดิมดำโปร่ง 75%), มุม 4px, ไม่มีเงา, ตัวอักษร 14/24
- `nzTooltipColor` แบบ preset และสีกำหนดเองยังใช้ได้เหมือนเดิม (override ไม่ทับ)
- รูปลูกศรเป็นของ ng-zorro (สามเหลี่ยม 16×8 บน 22.x, สี่เหลี่ยมหมุนบน 18.x) override กำหนดแค่สี
- Figma ไม่มีเงาของ tooltip สีขาว ซึ่งจะมองไม่เห็นบนพื้นขาว จึงใส่เงา popover ให้เอง ควรให้ designer ยืนยัน

## ยังไม่ครอบคลุม
- tooltip-bulletpoint และ Tooltips Modal (เนื้อหาซับซ้อน), ลูกศรขนาด 9×5 ของเฟรม themed (ใช้ขนาดของ ng-zorro)
