# v0.45.0 – Pagination และลูกศร Tooltip เหมือนกันทุกเวอร์ชันของ ng-zorro-antd
วันที่: 2026-11-23

## แก้ไข
- Pagination: ตัวเลือกจำนวนต่อหน้า (size changer) กว้างเท่ากันทุกเวอร์ชัน (59.8px) เดิม ng-zorro-antd 18 และ 19 ใส่ข้อความเป็น " 10 / page " มีช่องว่างหน้าหลัง ทำให้กว้างกว่า 3.2px (63px) และดันปุ่มหน้าถัดไปเลื่อน override ทำให้ข้อความนี้เป็น flex item ซึ่งตัดช่องว่าง (เฉพาะ item ที่ไม่มี `<span>` คือ 18 / 19) ผู้ใช้ 20 ขึ้นไปไม่เห็นการเปลี่ยนแปลง
- Tooltip ลูกศร: บน ng-zorro-antd 18 และ 19 (เดิมเป็นสี่เหลี่ยมมนหมุน 45° ในกล่อง 22px ห่างจากปุ่ม 14.3px) วาดใหม่เป็นสามเหลี่ยมมน 16x8 ในกล่อง 16px ห่างจากปุ่ม 12px และตำแหน่งลูกศรของ topLeft / topRight / bottomLeft / bottomRight / leftTop / leftBottom / rightTop / rightBottom (16px จากมุม) เหมือน 20 ขึ้นไปและ Figma ครบทั้ง 12 ตำแหน่ง ใช้ `:has()` แยกเวอร์ชัน (เฉพาะลูกศรที่มี `.ant-tooltip-arrow-content`) สีของลูกศรยังมาจาก `.ant-tooltip-arrow-content::before` สี preset จึงยังใช้ได้
- แก้บั๊กบน 20 ขึ้นไป: ลูกศรของ Tooltip ที่ใช้สี preset (`nzTooltipColor="red"` ฯลฯ) เดิมเป็นสีเทาเข้มไม่ตรงกับกล่อง (วัดเฉพาะบน 22.1.2 ก่อนแก้ ส่วน 20 / 21 ใช้กฎเดียวกัน) เพราะกฎของ override กดทับตัวแปรสีของลูกศร ตอนนี้ตั้งตัวแปรที่ตัว tooltip แทน ลูกศรจึงตรงสีกับกล่องทั้ง preset, สีกำหนดเอง, ธีม `aibox-tooltip-light` และ `aibox-tooltip-blue`
- ผลต่อผู้ใช้: 18 / 19 เห็นลูกศร Tooltip เป็นสามเหลี่ยมและ tooltip ชิดปุ่มขึ้น 2.3px (ห่าง 12px) และ size changer แคบลง 3.2px ส่วน 20 ขึ้นไปเห็นเฉพาะลูกศรสี preset ที่ถูกสี
- ตารางเวอร์ชันที่รองรับ (หน้า Getting started) และ README: เอาหมายเหตุ Pagination และลูกศร Tooltip ของ 19.3.1 ออก

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปเล็กที่มี Pagination และ Tooltip ครบ 12 ตำแหน่งพร้อม CSS ของ release นี้): size changer 59.8px ทั้ง 5 เวอร์ชัน; ทุกตำแหน่งของ Tooltip ห่างจากปุ่ม 12px กล่องลูกศร 16px จุดศูนย์กลางลูกศรเท่ากับ 22 ทุกตำแหน่ง
- เทียบภาพทั้งตาราง Tooltip 12 ตำแหน่งของ 18 / 19 / 20 / 21 กับ 22 ที่ความละเอียด 2x: ไม่มีพิกเซลที่ต่างเกิน 24/255 (เหลือแค่ขอบเนียน ซึ่ง 20 ต่างเท่ากัน)
- สีลูกศรเท่ากับสีกล่องบนทั้ง 5 เวอร์ชัน: ค่าเริ่มต้น, preset แดง, สีกำหนดเอง, light และ blue
- `npm test` ผ่าน (846 token)

## ยังไม่ครอบคลุม
- Tooltip ที่ไม่มีลูกศร (`nzTooltipArrowPointAtCenter` / ปิดลูกศร) และ RTL บน 18 / 19
- submenu ซ้อนใน Dropdown, ไอคอนในแถว, แถว danger / disabled
