# v0.53.9 – แก้ class aibox-select-dropdown--small ที่ไม่ทำงาน
วันที่: 2026-11-26

## แก้ไข
- `aibox-select-dropdown--small` (v0.53.8) ไม่มีผลเมื่อใส่ผ่าน `nzDropdownClassName`: ng-zorro ทุกเวอร์ชันที่วัด (18.2.1, 19.3.1, 20.4.4, 21.3.3, 22.1.2) ใส่ class นี้ที่ `div.cdk-overlay-pane` ซึ่งเป็น parent ของ `.ant-select-dropdown` แต่กฎเดิมเขียนเป็น `.ant-select-dropdown.aibox-select-dropdown--small` จึงไม่ตรงกับ element ใด ตอนนี้กฎเป็น `.aibox-select-dropdown--small .ant-select-item.ant-select-item` ใช้ได้ไม่ว่า class จะอยู่ที่ pane หรือ dropdown
- ตรวจผ่าน `nzDropdownClassName` จริงบนทั้ง 5 เวอร์ชัน: ก่อนแก้ แถวสูง 50, padding 12/16, 16/26 ทุกเวอร์ชัน (class อยู่ที่ pane) หลังแก้ แถวสูง 40, padding 8/16, 14/24 เท่ากันทุกเวอร์ชัน

## หมายเหตุ
- ใน v0.53.8 ผมวัดโดยเติม class ที่ `.ant-select-dropdown` เองใน DOM ซึ่งไม่ตรงกับที่ ng-zorro ทำจริง จึงไม่เห็นปัญหา ขอบคุณที่ site session จับได้
- วิธีใช้ไม่เปลี่ยน: `nzDropdownClassName="aibox-select-dropdown--small"`
