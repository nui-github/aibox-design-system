# v0.47.5 – Input: ตัวอักษรเริ่มตรงตำแหน่งใน Figma
วันที่: 2026-11-23

## แก้ไข
- Input / Textarea / Input number / กล่องที่มี prefix-suffix (Search, Password): ตัวอักษรเริ่มที่ 8px (large 12px) จากขอบซ้ายของกล่อง ตาม Figma textfield (`1:7052`), textarea (`1:7232`), search (`1:7587`) และ password (`6581:98500`): Figma วัดจากขอบนอกของกล่อง (เส้นขอบ 1px อยู่ข้างใน) เดิมเริ่มที่ 9px / 13px เพราะ padding 8px / 12px บวกเส้นขอบ 1px ลด padding แนวนอนลง 1px (7px / 11px) ทั้งด้านซ้ายและขวา Textarea ลด padding ทั้งสี่ด้านเช่นกัน: บรรทัดแรกเริ่มที่ 8px / 12px จากขอบบน
- Search: ไอคอนค้นหาเป็นกล่อง 20px (glyph 16px) ที่ 8px / 12px ข้อความเริ่มที่ 36px (large 40px) ตาม Figma เพิ่ม `margin-inline-start: 2px` และเพิ่ม `margin-inline-end` เป็น 10px ให้ prefix ของ `aibox-search`
- ไอคอนท้ายกล่อง (ตา, ปุ่มล้างค่า): ห่างขอบขวา 10px (large 14px) เหมือนเดิม (v0.47.4) แต่ใช้ `margin-inline-end: 2px` แทน 1px เพราะ padding ลดลง และใช้กับปุ่มล้างค่า (`.ant-input-clear-icon`, `.anticon-close`, `.anticon-close-circle`) ด้วย ตาม icon-cta ของ Search ใน Figma
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2: ตัวอักษรเริ่มที่ 8px / 12px (Input, Input number, Password), 8px / 12px จากบนและซ้ายใน Textarea, 36px / 40px ใน Search, ไอคอนค้นหาที่ 10px / 14px และไอคอนตาห่างขอบขวา 10px / 14px เท่ากันทุกเวอร์ชัน ปุ่มล้างค่าห่างขอบขวา 10px วัดบน 18 / 19 / 22 (วัดในแอปทดสอบเล็ก ไม่ใช่ในหน้าเว็บเอกสาร)

## หมายเหตุ
- กล่องที่มี prefix ธรรมดา (`nzPrefix`) ไอคอนจะเลื่อนไปอยู่ที่ 8px / 12px จากขอบ ตรงกับตำแหน่งไอคอนใน Figma textfield (ไอคอนซ่อนอยู่ในดีไซน์) ส่วนตำแหน่งข้อความหลังไอคอนยังไม่มีในดีไซน์ จึงไม่ได้ปรับ
- Select, Date picker, Time picker ใช้ padding ของตัวเอง ไม่ได้ปรับในรอบนี้
