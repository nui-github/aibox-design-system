# v0.56.3 – Steps แบบจุด: จุดอยู่กลางข้อความ และแถวย่อตามจอมือถือ
วันที่: 2026-11-27

## แก้ไข
- จุดของ `nzProgressDot` (แถวแนวนอน) อยู่กึ่งกลางข้อความแล้ว: ng-zorro วางจุดที่ 67px ในกล่อง 140px (กึ่งกลางที่ 71 ส่วนข้อความ 70) และดันจุดแรกไปอีก 2px จุดจึงอยู่ขวาข้อความ 1 ถึง 3px (วัดบน 22.1.2: จุดแรก +3, จุด 10px ของขั้นปัจจุบัน +2, จุด 8px อื่น +1) ตอนนี้ชดเชย 0 ทุกจุด
- ความกว้างของแต่ละขั้นเดิมตายตัว 140px ทำให้แถว 3 ขั้นกว้างอย่างน้อย 420px ถูกตัดหรือต้องเลื่อนบนมือถือ ตอนนี้ความกว้างตามจอ (ประมาณหนึ่งในสามของจอ ต่ำสุด 80px สูงสุด 140px ซึ่งเริ่มที่จอประมาณ 500px ขึ้นไป) จุดและเส้นตามไปด้วย แถว 3 ขั้นพอดีที่ 375px และ 320px โดยไม่ต้องเลื่อน ข้อความขึ้นบรรทัดใหม่ตามปกติ
- ค่านี้อิงความกว้างจอ ไม่ใช่ความกว้างกล่อง: ถ้าวาง Steps ในกล่องแคบบนจอกว้าง หรือมีมากกว่า 3 ขั้น ยังต้องเลื่อนหรือให้แอปจัดการเอง ส่วนแถวแนวตั้งของจุดไม่เปลี่ยน

## ตรวจแล้ว
- แถวจุด 3 ขั้น ทั้งปกติและ `nzSize="small"`: ชดเชยจุดต่อกึ่งกลางหัวข้อ 0 ทุกจุด และไม่มีการเลื่อนล้นที่จอ 1100 / 375 / 320 บน 18.2.1, 19.3.1, 20.4.4, 21.3.3, 22.1.2 ตรงกันทุกเวอร์ชัน
- หน้าเว็บ (22.1.2): ที่ 1100 กล่อง 140px, ที่ 375 กล่อง 98.3px, ที่ 320 กล่อง 80px ไม่มีการเลื่อนล้น ดูภาพ render แล้วจุดอยู่กลางข้อความ
- แถวแนวตั้งของจุดไม่ถูกแตะ (selector จำกัดเฉพาะแนวนอน)
- ยังไม่ได้ดู: มือถือจริง, Safari/Firefox, Steps ที่มีมากกว่า 3 ขั้น
