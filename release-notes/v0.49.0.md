# v0.49.0 – Dropdown: เมนูของการกระทำ (aibox-dropdown-actions) ตาม Figma Navigation > Dropdown Menu
วันที่: 2026-11-25

## เพิ่มใหม่
- class `aibox-dropdown-actions` บน `<ul nz-menu>` ใน `nz-dropdown`: เมนูของการกระทำตาม Figma หน้า Navigation > Dropdown Menu (dropdown-menu `10519:1909`, menu-item `10519:1908`) ซึ่งไม่เคยถูกใช้ใน override มาก่อน (override เดิมอ่านจากหน้า Popover > popover-submenu เท่านั้น) กล่องพื้น `bg/primary` มุม 4px เงา raise-modal padding บน/ล่าง 16px แถวสูง 50px (padding 12 16, gap 8, ตัวอักษร 16/26 `text/primary`) hover พื้น `bg/secondary` `nzDisabled` = ตัวอักษร `text/disable` ไอคอนนำหน้าอยู่ในกล่อง 20px (glyph 16px สี `text/icon-default`) ไม่มีลูกศรและหัวข้อ
- Figma: "Dropdown menu for actions, opened from a button such as เพิ่มเติม (Ant Dropdown) ... Code: nz-dropdown + nz-menu" และ "for choosing a value use dropdown / select (content-list) instead"
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): กล่อง 2 แถว = 132px (ตรง Figma), 3 แถว = 182px, แถวสูง 50px, ไอคอนกล่อง 20px ที่ 16px จากซ้าย, สีของแถว disabled `text/disable` เท่ากันทุกเวอร์ชัน และหน้าตา popover เดิมไม่เปลี่ยน
- เว็บเอกสาร: demo "Actions menu" ในหน้า Dropdown menu และแถวคลาสใหม่ในตารางหน้า Getting started

## หมายเหตุ
- Figma มีเมนู dropdown สองแบบ: popover-submenu (หน้า Popover: แถว 14/24 padding ข้าง 32px มีหัวข้อ มุม 8px) ซึ่งยังเป็นค่าเริ่มต้น และ Dropdown Menu ของหน้า Navigation (ใหม่กว่า แถว 50px) ที่เป็น opt-in ด้วย class นี้ ควรให้นักออกแบบยืนยันว่า `nz-dropdown` ควรใช้แบบไหนเป็นค่าเริ่มต้น (ถ้าเปลี่ยนค่าเริ่มต้นจะกระทบทุกแอปที่ใช้อยู่)
- ยังไม่มีใน Figma: submenu (`nz-submenu`) ในเมนู, แถว danger และสถานะ selected ของแบบนี้ (`nzSelected` ยังเป็นตัวอักษรสีน้ำเงินของแบบ popover)
