# v0.17.0 – Modal (dialog)
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ `nz-modal` / `NzModalService` ตาม Figma หน้า Modal: dialog (`1:9994`) พื้น `bg/primary` มุม 8px เงา raise-modal padding 32 gap 16 ชื่อเรื่อง 16/24 medium จัดกลาง
- ปุ่มท้าย dialog (dialog-cta แบบ horizontal `1:10244`): ปุ่มสองปุ่มกว้างเท่ากัน ห่าง 16px ขนาด large (48px) — ปุ่มที่ไม่ใช่ primary แสดงเป็น contained subsidiary (พื้นเทา) ปุ่ม primary เป็นสีน้ำเงิน
- dialog-alert (`1:9973`) ผ่าน `NzModalService.confirm / success / info / warning / error`: padding 32×48, ไอคอนสถานะ 32px แบบวงกลมทึบ (status-icon `1:10235`, สี `text/status/*-200`), ชื่อเรื่อง 16/24, ข้อความ 16/26 `text/secondary` จัดกลาง
- `aibox-modal-compact` (padding แบบมือถือ 24 16 20) และ `aibox-modal-cta-inset` (ปุ่มท้ายเว้นข้าง 120px สำหรับ dialog 800px) ใส่ผ่าน `nzClassName`
- หน้า Modal ในเว็บเอกสาร (route `/modal`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| size base 800 / small 400 | `nzWidth: 800` / `400` |
| padding-size desktop / mobile | ค่าเริ่มต้น / `nzClassName: 'aibox-modal-compact'` |
| dialog-cta horizontal | footer เริ่มต้น (Cancel + OK) หรือ `nzFooter` ที่มีปุ่มสองปุ่ม |
| dialog-alert status success / info / warning / fail | `modal.success / info / warning / error` |

## ที่ต้องรู้ก่อนอัปเกรด
- modal ทุกตัวเปลี่ยนหน้าตา: ไม่มีเส้นคั่นหัว/ท้าย พื้นที่ภายในเป็น 32px และมุมโค้ง 8px
- ปุ่มใน footer และ confirm ถูกบังคับเป็นขนาด large และปุ่มที่ไม่ใช่ primary/danger เป็น subsidiary โดยอัตโนมัติ
- ปุ่มปิด (X) ซ่อนเฉพาะใน dialog-alert; dialog ทั่วไปให้ตั้ง `nzClosable: false` เอง เพราะ Figma ไม่มีปุ่มปิด
- ต้อง import `NzModalModule` (ใน ng-zorro 22 ตัว service ถูก provide ผ่านโมดูลนี้)
- `confirm` ใช้ไอคอนเดียวกับ warning (Figma ไม่มี variant คำถาม)

## ยังไม่ครอบคลุม
- status=loading, dialog-cta แบบ vertical / button / button with checkbox / horizontal combine, scrollbar 4px, Password Protection overlay, dark theme
- สี mask (พื้นหลังด้านหลัง modal) ใช้ของ ng-zorro เพราะไม่ได้อ่านจาก Figma
