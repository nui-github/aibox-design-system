# v0.54.0 – คอลัมน์ปฏิทิน, แถบท้ายปฏิทิน, แถวมีคำอธิบายใน Select, ลูกศร Tree (ชุดที่ 4)
วันที่: 2026-11-26

## แก้ไข
- ปฏิทิน (Date picker และ Range picker): ตารางวันกว้าง 244px ตาม Figma คอลัมน์ละ 34.84px (เดิม 36px) ng-zorro ตั้งความกว้างตารางและ th ไว้ที่ 252px / 36px ทำให้ตารางเกินช่องที่เหลือหลัง padding 18px ไป 8px และคอลัมน์ขวาสุดชิดขอบมากกว่าซ้ายสุด ตรวจบน 18.2.1, 19.3.1, 20.4.4, 21.3.3, 22.1.2 ได้ 34.84px เท่ากันทุกเวอร์ชัน
- ลูกศรของ Tree และ Tree select: glyph 16px ในกล่อง 20px (เดิม 12px) ตาม Figma caret-right / caret-down (วัดบน 22.1.2: svg 16 × 16)

## ใหม่
- แถบท้ายปฏิทิน (`[nzRenderExtraFooter]`): เส้นบน 1px `rgba(0,0,0,.06)`, padding 4 24, แถวสูง 32, ข้อความ 14/16 medium `text/primary` ตาม Figma date-picker-range Footer (4558:7930) แถบท้ายของ Time picker ไม่เปลี่ยน
- แถวที่มีคำอธิบายใน Select (`<nz-option nzCustomContent>` + `aibox-option` / `-icon` / `-text` / `-title` / `-desc` ชุดเดียวกับ Cascader): แถวสูง 74px และ 62px เมื่อใช้ `aibox-select-dropdown--small` (หัวข้อ 14/24, คำอธิบาย 12/22) วัดบน 22.1.2

## เอกสาร
- หน้า Select: demo "Rows with description"; หน้า Date picker: demo "Range picker with footer"; ตาราง Class เสริมบอกว่า aibox-option ใช้กับ Select ได้

## ตรวจแล้วและไม่แก้
- ความสูงแถววันของ Range picker: Figma เฟรม range วาดแถว 28px ห่าง 4px (รวม 32px ต่อแถว) แต่เฟรม single date วาดแถว 30px และ ng-zorro ใช้ DOM เดียวกัน จึงคงแถว 30px ไว้ (ต้องให้ designer ยืนยันว่าสองเฟรมนี้ตั้งใจให้ต่างกันหรือไม่)
- ไอคอนคนใน avatar แบบทึบ (B6): Ant Design icons ไม่มี user แบบ fill ต้องใช้ SVG จาก Figma ยังไม่ได้ทำ

## หมายเหตุ
- แถวที่มีคำอธิบายใน Select และแถบท้ายปฏิทินวัดบน 22.1.2 เท่านั้น
