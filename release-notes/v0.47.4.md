# v0.47.4 – Password: ไอคอนตาห่างขอบขวาตาม Figma
วันที่: 2026-11-23

## แก้ไข
- Password: ไอคอนตา 16px ห่างขอบขวาของกล่อง 14px (large) / 10px (small) ตาม Figma Password (`6581:98500`, `10476:74`): ไอคอนอยู่ในกล่อง 20px ที่ห่างขอบ 12px (8px ใน small) และ glyph เข้าไปอีก 2px เดิมห่าง 13px / 9px เพราะกรอบ 1px บวก padding 12px / 8px เพิ่ม `margin-inline-end: 1px` ให้ `.ant-input-suffix` ที่มีไอคอนตา (ทั้ง `eye` และ `eye-invisible`)
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2: ระยะจากขอบขวา 14px (กล่อง 48px) และ 10px (กล่อง 40px) เท่ากันทุกเวอร์ชัน และตำแหน่งแนวตั้งยังอยู่กึ่งกลาง (กลางที่ 24 / 20)

## หมายเหตุ
- ตัวอักษรใน Input เริ่มที่ 13px (large) / 9px (small) จากขอบซ้าย ขณะที่ Figma `content` เริ่มที่ 12px / 8px ทุกเวอร์ชันเท่ากัน ไม่ได้แก้ในรอบนี้
- ปุ่มล้างค่า (`nzAllowClear` บน 22) และไอคอนอื่นใน suffix ไม่เปลี่ยน
