# v0.35.0 – label และข้อความช่วยตามขนาดช่อง (12/22 ปกติ, 14/24 เมื่อช่อง large)
วันที่: 2026-11-17

## แก้ไข
- label ของฟอร์ม, ข้อความช่วย (`nzExtra`), ข้อความ error (`nzErrorTip`) และตัวนับของ textarea ตามขนาดช่องเหมือน Figma: ช่องขนาดปกติ (Figma small) = **12/22** (letter-spacing 0.2) จากเดิม 14/24 และ form item ที่มีช่อง `nzSize="large"` (Input, Select, Input number, Date picker) = **14/24** ตรวจจากช่องที่อยู่ข้างในด้วย `:has()` อัตโนมัติ
- ไอคอนในข้อความ error ปรับตำแหน่งตามขนาดตัวอักษร

## เพิ่มใหม่
- class `aibox-form-large` บน `nz-form-item` บังคับ 14/24 (คู่กับ `aibox-form-small` ที่บังคับ 12/22) สำหรับช่องที่ `:has()` ตรวจไม่เจอ
- เว็บเอกสาร: demo "Label and assistive text" (ช่องปกติและ large), แถว `aibox-form-large` ในตารางหน้า Getting started

## ผลกระทบ
- ทุกฟอร์มที่ใช้ช่องขนาดปกติ label และข้อความช่วยจะเล็กลงจาก 14px เป็น 12px (บรรทัดสูง 24 เป็น 22) ถ้าต้องการให้บางฟอร์มเป็น 14/24 เหมือนเดิม ใส่ `aibox-form-large` บน `nz-form-item`

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1, 20.4.4 และ 22.1.2 ได้ค่าเท่ากัน

## ยังไม่ครอบคลุม
- ช่องว่างระหว่าง label กับกล่อง (Figma 4px) ยังเป็นค่าของ ng-zorro
