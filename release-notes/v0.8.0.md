# v0.8.0 – Chip / filter

## เพิ่มใหม่
- override ของ `nz-tag nzMode="checkable"` ตาม chip/filter ใน Figma (node `1:10199`): ยังไม่เลือก = ฟ้าอ่อน, hover = ฟ้าเข้ม, กด = ฟ้าเข้มกว่า, เลือกแล้ว (`nzChecked`) = ฟ้าเข้ม ตัวอักษรขาว, มุม 4px
- ขนาด: ค่าเริ่มต้น = small (สูง 32), `aibox-tag-xs` (24), `aibox-tag-md` (42, ตัวอักษร 16), `aibox-tag-lg` (42, ตัวอักษร 18)
- `aibox-tag-disabled` สำหรับสถานะ disabled

## ที่ต้องรู้ก่อนอัปเกรด
- `aibox-tag-disabled` เปลี่ยนแค่หน้าตา ต้องกันการคลิกเองในโค้ด
- tag แบบ checkable ทุกตัวเปลี่ยนหน้าตา

## ยังไม่ครอบคลุม
- ไอคอนนำหน้า (Figma มีหัวใจ 12px บน chip ที่เลือก), chip สีแดงที่เลือกแล้ว, chip/assist, chip/input (ปิดได้), Tags default/active
