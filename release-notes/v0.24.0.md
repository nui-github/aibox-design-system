# v0.24.0 – Date picker
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ `nz-date-picker` และ `nz-range-picker` ตาม Figma หน้า DatePicker (date-picker `1347:23603`, date-picker-range `4558:7666`)
- ช่อง: กล่องเดียวกับ Input override (ขอบ 1px `state/form/default` มุม 4px) ขนาดเล็ก padding 4×8 ตัวอักษร 14/24 และ `nzSize="large"` สูง 48px padding 8×12 ตัวอักษร 16/26, placeholder สี `text/placeholder`, ไอคอนปฏิทินสี `text/icon-default`, ขอบ hover/โฟกัสสี main พร้อมวงนอก 2px, `nzStatus="error"` ขอบแดงและวงแดง, disabled พื้นเทาตัวอักษรสี `text/disable`
- ปฏิทิน: กว้าง 280 พื้น `bg/primary` มุม 4px เงา raise-modal, หัว 1px เส้นล่างสี `border/primary` ชื่อเดือน 14/22 semibold ลูกศรสี `text/secondary`, ช่องวัน 24×24 มุม 4px (แถวสูง 30), วันที่ของเดือนอื่นสี `text/icon-default`, วันนี้ตัวหนาสี `color/main`, วันที่เลือกพื้น `color/main` ตัวอักษรขาว, ช่วงวันที่ใน range พื้น `bg/tertiary`
- หน้า Date picker ในเว็บเอกสาร (route `/date-picker`) ตั้ง locale ภาษาไทย (ชื่อวันภาษาไทย)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| size large / small | `nzSize="large"` / ค่าเริ่มต้น |
| state error | `nzStatus="error"` |
| state disabled | `nzDisabled` |
| expanded / edit | ปฏิทินที่เปิดจากช่อง (ใส่ `[nzShowToday]="false"` เพราะ Figma ไม่มี footer) |
| date-picker-range | `<nz-range-picker>` |

## ที่ต้องรู้ก่อนอัปเกรด
- ng-zorro 22 ต้องมี date adapter ใน providers (`provideNzNativeDateAdapter()` หรือ `provideNzDateFnsAdapter()`) ไม่งั้น NG0201 — ng-zorro 18 ไม่ต้อง (ใช้ date-fns ในตัว)
- `nz-date-picker` / `nz-range-picker` ทุกตัวเปลี่ยนหน้าตา
- สีพื้นของวันที่ที่เลือก (`color/main`) และสี hover ของช่องวัน (`bg/secondary`) เป็นค่าที่ผมอนุมานจากเฟรม range เพราะเฟรมวันที่เดี่ยวใน Figma ไม่แสดงวันที่เลือก ควรให้ designer ยืนยัน

## ยังไม่ครอบคลุม
- ชื่อเดือนแบบเต็มและปีพุทธศักราช (Figma แสดง "มกราคม 2537") ขึ้นกับ date adapter / locale ของแอป ปัจจุบันเว็บแสดง "1994 ม.ค."
- แผง month / year / decade, week / quarter picker, เวลาในปฏิทิน, ปุ่ม today, presets
- สถานะ range ที่เลือก/ใช้งานอยู่ทุกแบบ ตรวจเฉพาะสไตล์ในช่วงวันที่ตามที่อ่านจากโค้ดของ Figma ไม่ได้เทียบภาพ
