# v0.53.6 – แก้ดาว required ที่หายในฟอร์มแนวตั้ง
วันที่: 2026-11-26

## แก้ไข
- ดาว required (v0.53.5) ไม่แสดงในฟอร์มแนวตั้ง (`nzLayout="vertical"` และ `.ant-form:not(.ant-form-inline)` ที่ item ไม่ใช่ horizontal): ng-zorro ซ่อน `::after` ของ label ในฟอร์มแบบนี้ด้วย `display: none` (เพื่อซ่อน colon) และกฎดาวใหม่ที่ย้ายไปไว้ที่ `::after` ไม่ได้ตั้ง `display` จึงถูกซ่อนไปด้วย (ค่า computed ถูกต้องแต่ไม่แสดง) ตอนนี้กฎดาวตั้ง `display: inline` ทั้งกฎทั่วไปและกฎของฟอร์มแนวตั้ง
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก) ทั้ง 3 ทิศทาง: แนวตั้ง (ดาวแสดง, label ที่ไม่ required ยังซ่อน colon, ความสูง label 22px เท่าเดิม), แนวนอน (ดาวแสดงแทน colon, label ที่ไม่ required ยังมี colon) และ inline (ดาวแสดง) ค่าเท่ากันทุกเวอร์ชัน

## หมายเหตุ
- v0.53.5 ผมวัดดาวบนฟอร์มแนวนอนเท่านั้น (แอปทดสอบไม่มีฟอร์มแนวตั้ง) release note บอกว่า "วัดบนทุกเวอร์ชัน" ซึ่งจริงสำหรับแนวนอนเท่านั้น: ตอนนี้ทดสอบครบทั้ง 3 ทิศทางแล้ว ขอบคุณที่ site session จับได้
