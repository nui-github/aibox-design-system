# v0.40.0 – เส้น Divider ใช้ component/divider, Tag Selection แบบมีชื่อคน, ลบ token เก่า 3 ตัว
วันที่: 2026-11-18

## ⚠ ลบ token (เปลี่ยนแบบ breaking ตามกติกา README: ลบ token = major; repo ยังเป็น 0.x จึงขึ้นเลขกลาง)
- ลบ `--aibox-spacing-value-2` (2px), `--aibox-spacing-value-15` (15px) และ `--aibox-radius-value-6` (6px) ซึ่ง Figma ไม่มีแล้ว (ไม่มี override หรือเว็บเอกสารใช้) สเกลปัจจุบันไม่มีค่าเท่ากัน (spacing ขั้นละ 4px ตั้งแต่ `--aibox-spacing-1` = 4px, radius เริ่ม `--aibox-radius-2` = 4px) โปรเจกต์ที่ใช้ token เหล่านี้เองให้ใช้ค่าสเกลที่ใกล้ที่สุดหรือประกาศค่าเองในโปรเจกต์

## แก้ไข
- เส้น Divider ใช้ `component/divider` (#f1f2f3) ตาม Figma ทุกธีม: เส้น inline 1px (เดิม `border/primary`), เส้นของ divider ที่มีข้อความ, เส้นตั้ง และแถบ L (เดิม `bg/disable`) ส่วน Dash Secondary ยังใช้ `text/white-secondary` เหมือนเดิม

## เพิ่มใหม่
- Select หลายค่าแบบแท็กชื่อคน (Figma Tag Selection user selecting / user selected, node `3962:35682`): class `aibox-select-naming` บน `nz-select` + `[nzCustomTemplate]` ที่แสดง avatar กับชื่อ แท็กสูง 24px ขนาดปกติ (กล่อง 40px) และ 30px กับ `nzSize="large"` กล่อง 585px ที่มีแท็ก 5 อัน 3 แถวสูง 130px ตรงกับ Figma
- สี avatar ตาม Figma Avatar: `aibox-avatar-blue` (ค่าเริ่มต้น) / `-sea` / `-gray` / `-yellow` / `-red` ใช้ได้กับทั้งแท็กชื่อคน (`aibox-tag-naming`) และ Select
- เว็บเอกสาร: demo "Multiple with names" (หน้า Select), "Naming: avatar colours" (หน้า Tag), แถวคลาสใหม่ในหน้า Getting started, ข้อความของหน้า Divider

## ตรวจแล้ว
