# v0.39.1 – token ตรงกับ export ใหม่จาก Figma (คำอธิบาย token, สคริปต์แปลง)
วันที่: 2026-11-18

## ตรวจเทียบกับไฟล์ export ใหม่ (`design-tokens.tokens.json`, collection `Ai-BOX`)
- ไฟล์มี 1,042 รายการ แปลงเป็น DTCG ได้ 649 token (ไม่มี alias ที่หาไม่เจอ) เทียบกับ `tokens/*.json` แล้ว **ค่าและชนิดตรงกันทุกตัว** ไม่มี token ใหม่ที่ repo ยังขาด และไม่มีค่าที่ต้องแก้ (ค่า border scale, font weight 400/500/600, `gray-90`, `bg-subtle`, `component-divider` ที่แก้ใน v0.39.0 ตรงกับ Figma แล้ว)

## แก้ไข
- คำอธิบาย (`$description`) ของ 15 token อัปเดตตาม Figma: `border/1`–`border/10` (บอกสเกลทั้งชุดและชื่อ CSS), `color/bg/subtle`, `color/component/divider`, `font/weight/regular`, `/medium`, `/semibold` (ค่าเดิม ไม่เปลี่ยน)
- สคริปต์แปลง `scripts/figma-export-to-dtcg.py` รองรับ export ใหม่: ชื่อ collection `ai-box` (เดิม `i-box`) และ font weight ที่ export มาเป็น dimension (400 / 500 / 600) ให้ออกมาเป็นเลข `fontWeight` ไม่ใช่ `400px`

## ผลต่อโค้ด
- ไม่มีการเปลี่ยนค่า CSS ใดๆ (เปลี่ยนเฉพาะคอมเมนต์คำอธิบายใน `dist/tokens.css`) ไม่กระทบ component

## ยังค้าง (ต้องตัดสินใจ)
- token เก่า 3 ตัวที่ไม่มีใน export ใหม่แล้ว: `--aibox-spacing-value-2`, `--aibox-spacing-value-15`, `--aibox-radius-value-6` (ไม่มีที่ใดใน override หรือเว็บเอกสารใช้) การลบเป็นการเปลี่ยนแบบ major ตามกติกา README จึงยังไม่ลบ
- `--aibox-shadow-base-header-mobile`, `--aibox-shadow-base-bottom` และ `--aibox-blur-*` ยังไม่อยู่ใน export (ไม่มีค่าใน export) จึงคงค่าที่เพิ่มจากเอกสารใน v0.39.0 ไว้
