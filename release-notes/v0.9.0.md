# v0.9.0 – Badge
วันที่: 2026-11-04

## เพิ่มใหม่
- override ของ `nz-badge` ตาม Badge / Basic ใน Figma (node `1175:641`): ตัวเลข (18 / 22 / 26px), จุด (6 / 10 / 12px) และไอคอน พื้นแดง `error-100` ตัวอักษรขาว ขอบขาว 1px ภายในกล่อง
- ขนาด: Small = `nzSize="small"`, Medium = ค่าเริ่มต้น, Large = class `aibox-badge-lg`
- จุดสีเขียวด้วย `nzColor="green"`
- badge ไอคอน: class `aibox-badge-icon` (+ `aibox-badge-sm` / `aibox-badge-lg`) กับ `[nzCount]` เป็น template ที่ element มี class `ant-scroll-number-custom-component`

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-badge` ทุกตัวเปลี่ยนหน้าตา: ขอบขาวอยู่ในกล่อง (ไม่ใช่เงาด้านนอก), count ปกติสูง 22px (เดิม 20px), `nzSize="small"` สูง 18px (เดิม 14px)
- จุด (`nzDot`) ใหญ่ขึ้นเป็น 10px ในขนาดปกติ (เดิม 6px) ใช้ `nzSize="small"` เพื่อได้ 6px
- ตัวเลข 3 ตัวอักษรขึ้นไป (เช่น "99+") ขยายเป็นรูปแคปซูล

## ยังไม่ครอบคลุม
- status badge (`nzStatus` / `nzText`), ribbon, สี preset อื่นนอกจากเขียว
- Figma ใช้จุดสีแดงใน Small และสีเขียวใน Medium/Large: ที่นี่ทุกขนาดเป็นสีแดงโดยปริยายและใช้ `nzColor="green"` เมื่อต้องการสีเขียว (ควรให้ designer ยืนยัน)
