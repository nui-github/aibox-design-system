# v0.16.0 – Message (snackbar) และ message bar
วันที่: 2026-11-09

## เพิ่มใหม่
- override ของ `NzMessageService` (toast) เป็น snackbar ตาม Figma หน้า Message & Snack Bar (`1:10863`): พื้นตามสถานะ `bg/status/*-100`, padding 12×16, มุม 4px, gap 8px, ข้อความ 16/26 `text/primary`, เงา `0 4px 4px / 0 -1px 4px` (Figma raise-bg-none-sm, ค่าเดียวกับปุ่ม pagination)
- ไอคอนสถานะ 20px แบบวงกลมเส้น (วาดด้วย CSS แบบเดียวกับ alert)
- `aibox-snackbar-action` (ปุ่มข้อความ 12/16 medium สีเทา) และ `aibox-snackbar-close` (xmark 12px) สำหรับปุ่มท้าย snackbar — ใส่ในเทมเพลตที่ส่งเป็นเนื้อหาของ message
- message bar (`6608:120690`): `nz-alert` + `aibox-alert-bar` แถบสี `bg/secondary` มุม 4px ข้อความ 14/24 ไอคอน info 12px สี `color/main` ปุ่มปิดชิดขวา 12px จัดกลาง; เพิ่ม `aibox-alert-bar-left` สำหรับ Align left
- หน้า Message ในเว็บเอกสาร (route `/message`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| snackbar success / info / warning / error | `message.success / info / warning / error` |
| suffix text button / close | `aibox-snackbar-action` / `aibox-snackbar-close` ในเทมเพลตเนื้อหา |
| message bar (Default / Align left) | `<nz-alert class="aibox-alert-bar [aibox-alert-bar-left]" nzType="info" nzShowIcon nzCloseable>` |

## ที่ต้องรู้ก่อนอัปเกรด
- toast ของ `NzMessageService` ทุกตัวเปลี่ยนหน้าตา (พื้นสีตามสถานะ ไอคอนเส้น เงาใหม่) และไอคอนของ ng-zorro ถูกซ่อนแทนด้วยไอคอนของ override
- override ใช้กับ `.ant-message-custom-content` ที่ ng-zorro วาดใน overlay ส่วนกลาง จึงไม่ต้องใส่ class
- ไอคอนใน message bar เป็นแบบทึบ (ตาม Figma) ต่างจาก alert ที่เป็นเส้น

## ยังไม่ครอบคลุม
- ตำแหน่ง/แอนิเมชันของ toast (ใช้ของ ng-zorro), `nzDuration`, type loading
- ปุ่มใน snackbar ต้องเขียนเองในเทมเพลต ng-zorro ไม่มี input สำหรับปุ่ม/ปุ่มปิด
- สีปุ่มข้อความท้าย snackbar ใช้ `button/texted/subsidiary/text/default`; hover/focus ยังไม่มีใน Figma
