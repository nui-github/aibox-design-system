# v0.44.0 – Dropdown menu: ระยะห่างจากปุ่ม 4px ทุกเวอร์ชันของ ng-zorro-antd
วันที่: 2026-11-23

## แก้ไข
- Dropdown menu (`nz-dropdown` + `nz-menu`): ระยะห่างระหว่างปุ่มกับแผงเมนูเป็น 4px ทุกเวอร์ชัน (ทั้งเมนูที่เปิดลงล่างและขึ้นบน) เดิม ng-zorro-antd 18 และ 19 ใช้ margin 6px บน `.ant-dropdown` ส่วน 20 ขึ้นไปได้ 4px จาก offset ของ overlay override ตั้ง margin 4px ให้เฉพาะเวอร์ชันที่ไม่มีคลาส `ant-dropdown-placement-*` (18 / 19)
- ผลต่อผู้ใช้ 18 / 19: เมนูชิดปุ่มขึ้น 2px (6px เป็น 4px) ผู้ใช้ 20 / 21 / 22 ไม่เห็นการเปลี่ยนแปลง
- ตารางเวอร์ชันที่รองรับ (หน้า Getting started) และ README: เอาหมายเหตุระยะห่าง 6px ของ 19.3.1 ออก

## ตรวจแล้ว
- วัดใน DOM จริงบน ng-zorro-antd 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปเล็กที่มีแค่ Dropdown พร้อม CSS ของ release นี้) ได้ค่าเท่ากัน: ระยะห่างจากปุ่ม 4px ทั้งเมนูที่เปิดลงล่าง (ปุ่ม 114.8px และ 320px) และเมนูที่เปิดขึ้นบน ความกว้างเมนูยังเป็น 101.6px / 95.1px เหมือน v0.43.0
- `nzArrow` มีตั้งแต่ ng-zorro 20 (18 / 19 ไม่มีลูกศร) จึงไม่เปลี่ยนค่าของ 20+ ที่ลูกศรเพิ่ม 8px
- `npm test` ผ่าน (846 token)
