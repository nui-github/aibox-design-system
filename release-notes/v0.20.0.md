# v0.20.0 – Scrollbar
วันที่: 2026-11-13

## เพิ่มใหม่
- คลาส `aibox-scrollbar` ตาม Figma หน้า Scrollbar (vertical `6903:54`, horizontal `7024:6514`): ราง 4px สี `bg/secondary` และแถบเลื่อนสี `text/tertiary` มุม 4px ทั้งแนวตั้งและแนวนอน
- ใส่ที่ element ที่เลื่อนได้ (`overflow: auto`) ตำแหน่งและความยาวแถบ (start / mid / end) เป็นของเบราว์เซอร์
- Chromium และ Safari วาดด้วย `::-webkit-scrollbar`; Firefox กำหนดความกว้างไม่ได้ จึงได้ `scrollbar-width: thin` พร้อมสีเดียวกัน
- หน้า Scrollbar ในเว็บเอกสาร (route `/scrollbar`)

## ที่ต้องรู้ก่อนอัปเกรด
- ไม่ใช่ component ของ ng-zorro และไม่กระทบ scrollbar ที่มีอยู่เดิม ต้องใส่คลาสเองเท่านั้น (เช่นที่ `.ant-modal-body` หรือกล่องรายการที่ต้องการ)
- อุปกรณ์สัมผัสที่ใช้ overlay scrollbar (OS เป็นคนวาด) จะไม่เห็นรูปแบบนี้
- ตรวจบน Chromium (headless) เท่านั้น; Safari และ Firefox ยังไม่ได้ตรวจ

## ยังไม่ครอบคลุม
- สถานะ hover / active ของแถบเลื่อน, การใช้อัตโนมัติกับ dialog/dropdown/select (Figma dialog มี scrollbar 4px แต่ยังไม่ได้ผูกให้)
