# v0.47.2 – Date picker และ Tooltip: ขนาดเท่ากันบน ng-zorro 18 / 19
วันที่: 2026-11-23

## แก้ไข
- Date picker popup: ng-zorro-antd 18 / 19 ใส่เส้นกรอบล่าง 1px ที่ `.ant-picker-panel` และใส่ padding 7.54px บน/ล่างให้ range dropdown (22 ไม่มีทั้งสองอย่าง) popup เดี่ยวจึงสูงกว่า 2px และ range สูงกว่า 16px ล้างทั้งสองอย่างแล้ว
- Tooltip (ตำแหน่ง left / right): บน 18 / 19 padding 12px สำหรับลูกศรอยู่ในกล่อง `max-width: 250px` ข้อความจึงกว้างแค่ 238px (22 = 250px) เพิ่ม max-width อีก 12px ให้ตำแหน่งซ้าย/ขวาบน 18 / 19
- ตรวจแล้วบน 18.2.1, 19.3.1 และ 22.1.2: popup เดี่ยว 280x267 (มี footer 280x330) range 560x267 และกล่องข้อความ tooltip long text กว้าง 250px เท่ากัน (ยังไม่ได้วัดบน 20 / 21; tooltip วัดเฉพาะตำแหน่ง right)

## หมายเหตุ
- Select แบบ `nzMode="multiple"` / `"tags"` บน 18 / 19 ไม่มีลูกศรโดยค่าเริ่มต้น (ng-zorro ไม่สร้าง element) CSS แก้ไม่ได้ ให้ใส่ `[nzShowArrow]="true"` ซึ่งตรวจแล้วว่าได้ผลเหมือน 22
