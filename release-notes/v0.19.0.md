# v0.19.0 – Dropdown menu (popover submenu)
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของเมนูใน `nz-dropdown` (`nz-menu`) ตาม Figma หน้า Popover: popover-submenu (`1346:1358`, `5728:10508`) พื้น `bg/primary` มุม 8px เงา popover ไม่มี padding รอบเมนู
- แถวเมนู 14/24 padding 8×32 สีเทา (`button/contained/subsidiary/text`), แถวแรกห่างบน 16px และแถวสุดท้ายห่างล่าง 16px, แถวที่เลือก (`nzSelected`) ตัวอักษรสี `color/main` ไม่มีพื้น, hover พื้น `bg/secondary`
- หัวข้อ section (`nz-menu-group nzTitle`): 12/22 medium สี gray g-3, padding 8×16 (หัวข้อแรกห่างบน 16px) พื้นเทาอ่อน
- ลูกศร (`nzArrow`) ใช้สีขาว `bg/primary`
- token ใหม่ `--aibox-dropdown-section-bg` (#f7f7f7) ใน `tokens/component.json` เพราะ Figma ใช้ค่านี้โดยไม่มีตัวแปร
- หน้า Dropdown menu ในเว็บเอกสาร (route `/dropdown`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| section=no | `<ul nz-menu>` กับ `<li nz-menu-item>` |
| section=yes | จัดกลุ่มด้วย `<li nz-menu-group nzTitle="...">` |
| position right / bottom | `nzPlacement` + `nzArrow` |
| แถวที่ active (สีน้ำเงิน) | `nzSelected` |

## ที่ต้องรู้ก่อนอัปเกรด
- เมนูใน dropdown ทุกตัวเปลี่ยนหน้าตา (มุมโค้ง 8px, แถวกว้างขึ้น padding 32px)
- ng-zorro 18.x ใช้ชื่อโมดูล `NzDropDownModule` ส่วน 22.x ใช้ `NzDropdownModule` (d ตัวเล็ก)
- สี hover (`bg/secondary`) เป็นค่าที่ผมเลือกเอง เพราะ Figma ไม่มีสถานะ hover ควรให้ designer ยืนยัน
- popover ธรรมดา (`nz-popover`, node `1346:1149`) ในหน้าเดียวกันเป็น Ant Design มาตรฐาน (ฟอนต์ SF Pro, ไม่มี token) จึงไม่ได้ override

## ยังไม่ครอบคลุม
- submenu ซ้อนในเมนู (`nz-submenu`), ไอคอนในแถว, แถว danger/disabled
- ตำแหน่งลูกศรทั้ง 12 placement ตรวจเฉพาะ bottomLeft
