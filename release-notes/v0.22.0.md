# v0.22.0 – Table
วันที่: 2026-11-13

## เพิ่มใหม่
- override ของ `nz-table` ตาม Figma หน้า Table: table head cell (`3631:1869`) พื้น `bg/secondary` padding 12×8 ตัวอักษร 14/24 medium สี `text/primary` สูง 48px ไม่มีเส้นคั่นคอลัมน์
- ไอคอนเรียงลำดับ 16px ห่างจากหัวข้อ 8px: ยังไม่เรียง = ลูกศรขึ้น-ลงสีเทา (`text/icon-default`), เรียงอยู่ = ลูกศรเดียวสีน้ำเงิน (`text/main`) ขึ้นเมื่อ ascend ลงเมื่อ descend (วาดด้วย CSS แทน caret ของ ng-zorro)
- table row cell (`8794:180479`) พื้น `bg/primary` padding 8 สูงขั้นต่ำ 58px ตัวอักษร 16/26 regular; ไม่เปลี่ยนสีพื้นเมื่อ hover
- `aibox-btn-nopad` สำหรับปุ่ม texted ไม่มี padding ซ้าย-ขวา (Button type "without padding") ใช้กับ `aibox-btn-xs` ในแถว action ห่างกัน 20px
- หน้า Table ในเว็บเอกสาร (route `/table`)

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| table head cell sort=no | `<th>` ธรรมดา |
| sort=default / sorted | `<th [nzSortFn]>` ยังไม่เรียง / `nzSortOrder` ascend หรือ descend |
| row cell type=text | `<td>` |
| row cell type=badge | `<nz-tag>` (override ของ Tag) ใน `<td>` |
| row cell type=action | `<button nz-button nzType="text" class="aibox-btn-xs aibox-btn-nopad">` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-table` ทุกตัวเปลี่ยนหน้าตา: หัวตารางพื้นเทา ไม่มีเส้นคั่นคอลัมน์ padding 8px และแถวสูงอย่างน้อย 58px
- เส้นคั่นแถว 1px สี `bg/secondary` เป็นค่าที่ผมเพิ่มเอง Figma แสดงเฉพาะ cell เดี่ยว ไม่มีเส้นคั่น ควรให้ designer ยืนยัน
- สี hover ของแถวถูกปิด (คงพื้นขาว) เพราะ Figma ไม่มีสถานะ hover

## ยังไม่ครอบคลุม
- เครื่องหมาย required (*) สีแดงและไอคอนข้อมูล (tooltip) ในหัวคอลัมน์ ซึ่ง ng-zorro ไม่มี input ต้องใส่เองในเทมเพลตของ `<th>`
- คอลัมน์เลือกแถว / ขยายแถว, header ตรึง, ตารางแบบ bordered และ small
- ตัวแบ่งหน้า (ใช้ override ของ Pagination แยกต่างหาก)
