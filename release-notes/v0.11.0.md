# v0.11.0 – Tab
วันที่: 2026-11-09

## เพิ่มใหม่
- override ของ `nz-tabs` ตาม Figma หน้า Tab (tab / Tab Button node `4034:247`, Outline Tab `5342:5164`, Tab content `5264:730`)
  - `nzType="card"` = แท็บยก 4px มุมบน: ขนาด Large / Medium / Small สูง 48 / 40 / 32px, แท็บที่เลือกพื้นขาว ตัวอักษรน้ำเงิน, แท็บปกติพื้น `gray-80` ตัวอักษรเทา, disabled พื้นเทา
  - แบบ line (ค่าเริ่มต้น) = รางหนา 4px + แถบ 4px สีน้ำเงิน: สูง 56 / 40 / 40px
  - `nzSize="large"` / ค่าเริ่มต้น / `"small"` เลือกขนาด
- class เสริม: `aibox-tab-icon` ไอคอนจุด 12px ในหัวข้อแท็บ (`aibox-tab-icon-error` / `aibox-tab-icon-success` สำหรับไอคอนสถานะ), `aibox-tabs-fill` ให้แท็บแบ่งความกว้างเท่ากัน

## จับคู่กับ ng-zorro
| Figma | ng-zorro |
|---|---|
| tab / Tab Button | `nzType="card"` |
| Outline Tab | `nzType="line"` (ค่าเริ่มต้น) |
| Size Large / Medium / Small | `nzSize="large"` / ค่าเริ่มต้น / `"small"` |
| state Active / Default / Disabled | แท็บที่เลือก / แท็บอื่น / `nzDisabled` บน `nz-tab` |
| ไอคอนจุด, error, success | `aibox-tab-icon`, `-error`, `-success` |

## ที่ต้องรู้ก่อนอัปเกรด
- `nz-tabs` ทุกตัวเปลี่ยนหน้าตา: แท็บแบบ line มีรางหนา 4px (เดิม 1px) แถบ 4px (เดิม 2px) ระยะห่างระหว่างแท็บเป็น padding ของแท็บ (ไม่มี margin 32px แล้ว) ตัวอักษร 16px (small 14px) น้ำหนัก 500
- Figma ไม่มี hover: แท็บปกติเปลี่ยนเป็นสีหลักตอน hover; line แบบ Small (สูง 40px, ตัวอักษร 14, padding 12px) อนุมานจากความสูงของเฟรม Outline Tab ไม่ได้อ่านจาก node
- เว็บ docs: แท็บของตัวเว็บ (แท็บ CSS ใต้แต่ละหน้า) ใช้ override นี้ด้วย จึงเปลี่ยนหน้าตาตามไปเอง
