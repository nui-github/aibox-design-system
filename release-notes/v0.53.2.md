# v0.53.2 – Menu: แถวสูง 56px ติดกัน (ตรง Figma) ไม่มีช่องว่าง 8px
วันที่: 2026-11-25

## แก้ไข
- Menu แนวตั้ง (`nz-menu nzMode="inline"`, Figma Navigation `154:3272`): ตรวจซ้ำกับ Figma แล้วพบ 3 จุดที่เกินมาจากที่ Figma วาด รวม 10px ในเมนูตัวอย่าง (258px เทียบกับ Figma 248px = 56 + 192)
  - แถวบนสุดที่เป็น `nz-menu-item` สูง 57px: เส้นล่าง 1px ใน Figma อยู่ "ข้างใน" ความสูง 56px จึงลด padding ล่างเหลือ 15px (รูปแบบเดียวกับที่เจอใน Input / Collapse / Card)
  - ng-zorro ใส่ margin-bottom 8px ระหว่างแถวบนสุด (ใน Figma แถวชิดกัน): เอาออก
  - กลุ่มที่เปิด (`nzOpen`): padding ล่าง 24px + เส้น 1px ของกลุ่ม ทำให้สูง 193px เทียบกับ Figma 192px: ลด padding เหลือ 23px
- ตรวจแล้วบน 18.2.1, 19.3.1, 20.4.4, 21.3.3 และ 22.1.2 (แอปทดสอบเล็ก): เมนูสูง 248px, แถวบนสุด 56px, หัวข้อกลุ่ม 56px, รายการย่อยเริ่มที่ y=56 + 56 และห่างกัน 8px เท่ากันทุกเวอร์ชัน
- เมนูด้านข้างของเว็บเอกสารไม่ได้ใช้กฎนี้ (วัดแล้วแถวยังสูง 40px ห่าง 8px เหมือนเดิม)

## หมายเหตุ
- ตรวจ Checkbox / Radio, Switch ด้วย: Switch ตรง Figma อยู่แล้ว (44x22 มาตรฐาน, 50x25 mobile, 51x31 ผ่าน `aibox-switch-ios`); Checkbox / Radio ทำกรอบตามขนาดกล่องที่มองเห็น (14 / 17.5 / 21px) ขณะที่ Figma วางกล่องไว้ในเฟรม 20 / 24 / 28px (เหลือขอบใส 3 / 3.25 / 3.5px) นี่เป็นเรื่องที่ต้องให้นักออกแบบตัดสินใจ ยังไม่ได้เปลี่ยน
