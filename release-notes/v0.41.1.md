# v0.41.1 – ตารางเวอร์ชันที่รองรับ: เพิ่ม ng-zorro-antd 19.3.1 และ 21.3.3
วันที่: 2026-11-18

## เพิ่มใหม่
- หน้า Getting started (ตารางเวอร์ชันที่รองรับ) และ README เพิ่ม ng-zorro-antd 19.3.1 และ 21.3.3 สถานะ "ตรวจแล้วบางส่วน"
- ไม่มีการเปลี่ยน CSS หรือ token (ไฟล์ `dist/` เหมือน v0.41.0 ยกเว้นเลขเวอร์ชัน)

## ตรวจแล้ว
- วัดเฉพาะ Select หลายค่า (แท็กชื่อคน และมุมมองคอลัมน์ / รายการ / กล่องเลื่อนได้) บน Angular 19.2 + ng-zorro-antd 19.3.1 และ Angular 21.2 + ng-zorro-antd 21.3.3 ได้ค่าเท่ากับ 18.2.1 / 20.4.4 / 22.1.2 ทุกค่า (กล่อง 460 x 40 และ 585 x 130, แท็ก 24 / 30px, คอลัมน์ 724 x 282, แท็กในรายการ 672 x 30)
- เว็บเอกสาร build ผ่านบน 21 ส่วนบน 19 build ทั้งเว็บไม่ได้ (ใช้ `nz-tabs`, `nz-input-wrapper`, `nz-input-password` ซึ่ง 19 ไม่มี) จึงวัดด้วยสำเนาที่เหลือหน้า Select

## ยังไม่ครอบคลุม
- component อื่นนอกจาก Select หลายค่าบน 19.x และ 21.x, และ 20.x อื่นนอกจาก 20.4.4
