# v0.34.0 – รองรับ ng-zorro-antd 20.x (แก้ Tab และ Cascader)
วันที่: 2026-11-17

## แก้ไข (พบจากการตรวจบน ng-zorro-antd 20.4.4 และ 18.2.1)
- Tab: ng-zorro 18.2.1 และ 20.4.4 วาดปุ่มของแท็บเป็น `<button>` (22 เป็น `<div>`) ทำให้เบราว์เซอร์ใส่ padding 1px 6px และน้ำหนักตัวอักษร 400 แท็บจึงกว้าง 131.9 x สูง 50px แทน 121.1 x 48px ตอนนี้รีเซ็ต padding / border / background / font ของปุ่มแล้ว วัดได้ 121.1 x 48px ตรงกับ 22 (บั๊กนี้มีอยู่ใน 18.2.1 มาตั้งแต่ปล่อย Tab)
- Cascader: ng-zorro 20 ใส่ margin 2px บน/ล่างให้แถวเมนู ทำให้แผงสูงกว่าคอลัมน์ 4px ตอนนี้ตั้ง margin เป็น 0 (ตรงกับ 22)

## ตรวจแล้ว
- สร้างเว็บเอกสารด้วย Angular 20.3 + ng-zorro-antd 20.4.4 แล้วเทียบกับ 22.1.2 ทุก demo ของ 29 หน้า (ขนาด สี ขอบ มุม ตัวอักษร padding) และสคริปต์วัดของ modal, message, dropdown, date / time picker, cascader, drawer, menu, tab ได้ค่าเท่ากัน ยกเว้นสองจุดข้างต้น
- ความต่างของ API ใน 20 ดู README หัวข้อ "Verified on ng-zorro-antd 20.4.4" (เช่น `NzDropDownModule`, ไม่มี `nzNeedConfirm`, ต้อง `registerLocaleData(th)`, `provideAnimationsAsync()`, zone.js หรือ zoneless)

## ยังไม่ได้ตรวจ
- 19.x และ 21.x, สถานะ hover / focus ของทุก component และแอป Ai-BOX จริง
